## Creating a Simple Age Verification System
To create a simple age verification system, we will use the following components:
* A user database to store information about registered users
* A machine learning model to predict user age based on their online behavior
* A Python script to integrate the user database and machine learning model

### User Database
We will use a simple SQLite database to store user information. The database will contain the following columns:
* `id`: a unique identifier for each user
* `username`: the username chosen by the user
* `age`: the self-reported age of the user
* `behavior_data`: a JSON object containing data about the user's online behavior

```python
import sqlite3

# Connect to the SQLite database
conn = sqlite3.connect('user_database.db')
cursor = conn.cursor()

# Create the user table
cursor.execute('''
    CREATE TABLE users (
        id INTEGER PRIMARY KEY,
        username TEXT NOT NULL,
        age INTEGER NOT NULL,
        behavior_data TEXT NOT NULL
    )
''')

# Commit the changes and close the connection
conn.commit()
conn.close()
```

### Machine Learning Model
We will use a simple random forest classifier to predict user age based on their online behavior. The model will be trained on a dataset containing user behavior data and corresponding age labels.

```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

# Load the user behavior dataset
behavior_data = pd.read_csv('behavior_data.csv')

# Split the dataset into training and testing sets
X_train, X_test, y_train, y_test = train_test_split(behavior_data.drop('age', axis=1), behavior_data['age'], test_size=0.2, random_state=42)

# Train the random forest classifier
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# Evaluate the model on the testing set
accuracy = model.score(X_test, y_test)
print(f'Model accuracy: {accuracy:.3f}')
```
