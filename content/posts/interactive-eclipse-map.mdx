The upcoming total solar eclipse on August 12 has generated significant interest among astronomy enthusiasts and developers alike. To cater to this interest, an open-source interactive map has been made available, providing a detailed and immersive experience for users. ## Features of the Map
The interactive map offers a range of features that make it an invaluable resource for anyone interested in the eclipse. Some of the key features include:

* Besselian elements: This feature provides detailed information about the eclipse, including the timing, duration, and path of the eclipse.
* Umbra live: This feature displays the current position of the umbra, the innermost and darkest part of the moon's shadow, in real-time.
* Shadow 3D: This feature provides a 3D representation of the moon's shadow, allowing users to visualize the eclipse in a more immersive way.
* Cloud projection: This feature projects the cloud cover onto the map, giving users an idea of the weather conditions during the eclipse.

## Getting Started with the Map API
To get started with the map API, developers will need to familiarize themselves with the available endpoints and parameters. The API uses a simple RESTful architecture, making it easy to integrate with existing applications.

```python
import requests

# Set the API endpoint and parameters
endpoint = "https://eclipsefan.org/api"
params = {
    "v": 2,
    "t": "max",
    "layers": "eclipse,besselian,umbra-live,shadow-3d,cloud-projection",
    "lat": 43.4623,
    "lon": -3.8099,
    "opacity": "besselian:0.2,umbra-live:0.2",
    "zoom": 6,
    "palier": "minute"
}

# Send a GET request to the API
response = requests.get(endpoint, params=params)

# Print the response
print(response.json())
```
