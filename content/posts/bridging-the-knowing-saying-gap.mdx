## Introduction

The Knowing-Saying Gap is a phenomenon that has significant implications for the deployment of language models in real-world applications. Recent research has shown that linear probes can detect corrupted context in language models with near-perfect accuracy, yet this does not translate into reliable failure prediction. In this tutorial, we will delve into the details of this gap and provide practical examples of how to work with probes to improve language model reliability.

## Understanding the Knowing-Saying Gap

The Knowing-Saying Gap refers to the dissociation between a language model's ability to detect corrupted context and its confidence in providing correct answers. This gap has significant implications for the deployment of language models in real-world applications, where reliability and accuracy are crucial. To understand this gap, let's consider an example of a language model that is tasked with answering a series of arithmetic questions.

```python
import numpy as np

# Define a simple language model that answers arithmetic questions
def language_model(question):
    # Tokenize the question
    tokens = question.split()
    
    # Extract the numbers and operator from the question
    num1 = int(tokens[0])
    operator = tokens[1]
    num2 = int(tokens[2])
    
    # Perform the arithmetic operation
    if operator == '+':
        answer = num1 + num2
    elif operator == '-':
        answer = num1 - num2
    elif operator == '*':
        answer = num1 * num2
    elif operator == '/':
        answer = num1 / num2
    
    return answer

# Test the language model
question = "2 + 2"
answer = language_model(question)
print(f"Answer: {answer}")
```

## Bridging the Knowing-Saying Gap

To bridge the Knowing-Saying Gap, we need to use the probe to detect corrupted context in the language model and adjust the confidence of the answer accordingly. We can do this by using the probe to predict the probability of error for each answer.

```python

    # Tokenize the question
    tokens = question.split()
    
    # Extract the numbers and operator from the question

    num2 = int(tokens[2])
```
