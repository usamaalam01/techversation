## Introduction

Multi-page visually-rich document understanding (MP-VRDU) is a complex task that requires managing evidence that is sparse, spread across pages, and often exceeds a model's context window. Prior work has produced competing, largely untested claims about how these systems should be built. In this tutorial, we will explore the three failure modes that can occur in MP-VRDU: representation, selection, and attribution. We will use the paper "Locating Failure in Multi-Page Visually Rich Document Understanding: An Empirical Attribution" as a reference and provide working code examples to demonstrate the concepts.

## Understanding Failure Modes

Before we dive into the implementation, let's understand the three failure modes that can occur in MP-VRDU:

*   **Representation Failure**: This occurs when the model is unable to represent the document accurately. This can happen when the model is not trained on a diverse set of documents or when the document contains complex layouts or tables.
*   **Selection Failure**: This occurs when the model selects the wrong information from the document. This can happen when the model is not able to identify the relevant information or when the document contains irrelevant information.
*   **Attribution Failure**: This occurs when the model is unable to attribute the correct source of the information. This can happen when the model is not able to identify the correct page or section of the document.

## Implementing Empirical Attribution

To implement empirical attribution, we need to follow these steps:

1.  **Data Preparation**: We need to prepare a dataset of multi-page documents with annotated answers.
2.  **Model Training**: We need to train a model to predict the answers based on the document content.
3.  **Failure Mode Detection**: We need to detect the failure mode for each incorrect answer.

Here is an example code snippet in Python that demonstrates how to implement empirical attribution:
```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# Load the dataset
df = pd.read_csv("data.csv")

# Split the data into training and testing sets
train_text, val_text, train_labels, val_labels = train_test_split(df["text"], df["label"], random_state=42, test_size=0.2, stratify=df["label"])

# Load the pre-trained model and tokenizer
model = AutoModelForSequenceClassification.from_pretrained("distilbert-base-uncased")
tokenizer = AutoTokenizer.from_pretrained("distilbert-base-uncased")

# Train the model
model.train()
for epoch in range(5):
    for batch in train_text:
        inputs = tokenizer(batch, return_tensors="pt")
        labels = train_labels[batch]
        optimizer = torch.optim.Adam(model.parameters(), lr=1e-5)
        loss = model(**inputs, labels=labels)
        loss.backward()
        optimizer.step()

# Evaluate the model
model.eval()
predictions = []
with torch.no_grad():
    for batch in val_text:
        inputs = tokenizer(batch, return_tensors="pt")
        outputs = model(**inputs)
        logits = outputs.logits
        predictions.extend(torch.argmax(logits, dim=1))

# Detect failure modes
failure_modes = []
for i, prediction in enumerate(predictions):
    if prediction != val_labels[i]:
        # Detect representation failure
        if model(**tokenizer(val_text[i], return_tensors="pt"))["logits"].argmax() != val_labels[i]:
            failure_modes.append("representation")
        # Detect selection failure
        elif model(**tokenizer(val_text[i], return_tensors="pt"))["logits"].argmax() == val_labels[i] and model(**tokenizer(val_text[i], return_tensors="pt"))["logits"].argmax() != prediction:
            failure_modes.append("selection")
        # Detect attribution failure
        else:
            failure_modes.append("attribution")

# Print the failure modes
print(failure_modes)
```
This code snippet demonstrates how to train a model to predict answers based on document content and detect failure modes for incorrect answers.

## Visualizing Failure Modes

To better understand the failure modes, we can visualize them using a heatmap. Here is an example code snippet that demonstrates how to visualize failure modes:
