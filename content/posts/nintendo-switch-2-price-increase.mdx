## Introduction
Nintendo has recently announced a price increase for the Switch 2 console, as reported on their [official website](https://www.nintendo.co.jp/corporate/release/en/2026/260508.html). This move is likely to impact gamers and developers alike. In this post, we will explore how developers can use web scraping to track price changes and make informed decisions.

## Web Scraping with Python
To track price changes, we can use web scraping techniques. We will use the `requests` and `beautifulsoup4` libraries in Python to scrape the Nintendo website and extract the current price of the Switch 2 console.

```python
import requests
from bs4 import BeautifulSoup

# Send a GET request to the Nintendo website
url = "https://www.nintendo.co.jp/corporate/release/en/2026/260508.html"
response = requests.get(url)

# Parse the HTML content using BeautifulSoup
soup = BeautifulSoup(response.content, 'html.parser')

# Find the price element on the page
price_element = soup.find('p', string=lambda s: s and 'Price' in s)

# Extract the price from the element
if price_element:
    price = price_element.text.split(':')[-1].strip()
    print(f"Current price: {price}")
else:
    print("Price not found")
```

## Handling Anti-Scraping Measures
Some websites may employ anti-scraping measures to prevent bots from scraping their content. To handle this, we can use techniques such as rotating user agents, adding delays between requests, and using proxies.

response = requests.get(url, headers=headers)

# Parse the HTML content using BeautifulSoup

# Find the price element on the page
