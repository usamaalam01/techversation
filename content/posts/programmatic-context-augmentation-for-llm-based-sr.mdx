## Introduction to Symbolic Regression
Symbolic regression (SR) is a fundamental challenge in scientific discovery, where the goal is to discover mathematical expressions that best describe a given dataset. Traditional approaches, primarily based on genetic algorithms and related evolutionary methods, have proven useful but suffer from scalability and expressivity limitations. Recently, Large Language Models (LLMs) have been applied to SR, offering a promising alternative.

## Programmatic Context Augmentation
Programmatic context augmentation is a technique that enhances LLM-based SR by providing more informative input. This approach involves augmenting the input data with additional context that helps the LLM to better understand the underlying relationships in the data. By doing so, the model can discover more accurate and complex mathematical expressions.

### Benefits of Programmatic Context Augmentation
The benefits of programmatic context augmentation include:

* Improved model performance: By providing more informative input, programmatic context augmentation can improve the performance of LLM-based SR models.
* Increased discoverability: Programmatic context augmentation can help uncover more accurate and complex relationships in the data, leading to increased discoverability of mathematical expressions.

## Implementing Programmatic Context Augmentation
To implement programmatic context augmentation, you can use the following steps:

1. **Prepare the input data**: Prepare the input data by augmenting it with additional context. This can include features such as variable names, data types, and units.
2. **Define the LLM model**: Define the LLM model architecture and configure it for SR.
3. **Train the model**: Train the model using the augmented input data.

### Example Code
Here is an example code in Python that demonstrates how to implement programmatic context augmentation:
```python
import pandas as pd
import numpy as np
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# Prepare the input data
data = pd.read_csv("data.csv")
data["context"] = data.apply(lambda row: f"{row['variable_name']} ({row['data_type']}) {row['unit']}", axis=1)

# Define the LLM model
model = AutoModelForSequenceClassification.from_pretrained("llm-base")
tokenizer = AutoTokenizer.from_pretrained("llm-base")

# Train the model
input_ids = []
attention_masks = []
for index, row in data.iterrows():
    inputs = tokenizer.encode_plus(
        row["context"],
        add_special_tokens=True,
        max_length=512,
        return_attention_mask=True,
        return_tensors="pt",
    )
    input_ids.append(inputs["input_ids"])
    attention_masks.append(inputs["attention_mask"])

input_ids = torch.cat(input_ids, dim=0)
attention_masks = torch.cat(attention_masks, dim=0)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)
input_ids = input_ids.to(device)
attention_masks = attention_masks.to(device)

optimizer = torch.optim.Adam(model.parameters(), lr=1e-5)
for epoch in range(5):
    model.train()
    optimizer.zero_grad()
    outputs = model(input_ids, attention_mask=attention_masks)
    loss = outputs.loss
    loss.backward()
    optimizer.step()
    print(f"Epoch {epoch+1}, Loss: {loss.item()}")
```
In this example, we first prepare the input data by augmenting it with additional context. We then define the LLM model architecture and configure it for SR. Finally, we train the model using the augmented input data.
