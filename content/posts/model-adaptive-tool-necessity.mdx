## Introduction

Large language models (LLMs) are increasingly being used as autonomous agents that must decide when to answer directly versus when to invoke external tools. Prior work has largely treated tool necessity as a model-agnostic property, annotated by human or LLM judge. However, this approach has limitations, as it mostly covers cases where the answer is obvious. In this tutorial, we will explore the concept of model-adaptive tool necessity and provide a step-by-step guide on working with it.

## Understanding Model-Adaptive Tool Necessity

Model-adaptive tool necessity refers to the ability of an LLM to determine when it needs to invoke an external tool to provide an accurate response. This is in contrast to model-agnostic tool necessity, which relies on human or LLM judges to determine tool necessity. Model-adaptive tool necessity is a more flexible and scalable approach, as it allows the LLM to adapt to different contexts and tasks.

To illustrate this concept, consider a scenario where an LLM is asked to provide information on the current weather. In a model-agnostic approach, the LLM would rely on pre-defined rules or human judges to determine whether to invoke a weather API or provide a direct response. In contrast, a model-adaptive approach would allow the LLM to determine the necessity of invoking the weather API based on the context of the question.
