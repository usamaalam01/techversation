## The Technology Behind In-Car Ads

The in-car advertising system used by BMW relies on a combination of data collection and machine learning algorithms to display targeted ads to drivers. The system uses data from various sources, including the vehicle's onboard computer, GPS, and external data providers, to create a profile of the driver's preferences and interests. This information is then used to display relevant ads on the vehicle's infotainment system.

```python
import pandas as pd

# Sample data collection
data = {
    'driver_id': [1, 2, 3],
    'location': ['New York', 'Los Angeles', 'Chicago'],
    'interests': ['sports', 'music', 'movies']
}

df = pd.DataFrame(data)

# Simple example of data processing for targeted ads
def get_targeted_ads(driver_id, location, interests):
    # Using a simple if-else statement for demonstration purposes
    if interests == 'sports':
        return 'Sports equipment ad'
    elif location == 'New York':
        return 'New York-based business ad'
    else:
        return 'Default ad'

# Applying the function to the sample data
df['targeted_ad'] = df.apply(lambda row: get_targeted_ads(row['driver_id'], row['location'], row['interests']), axis=1)

print(df)
```
