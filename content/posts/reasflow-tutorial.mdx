## Introduction
ReasFlow is a knowledge-based multi-agent system designed to assist reasoning-centric scientific discovery in applied mathematics. The system utilizes a combination of Large Language Models (LLMs) and a multi-agent framework to tackle complex tasks in mathematically grounded disciplines. In this tutorial, we will explore how to use ReasFlow to facilitate scientific discovery.

## Setting Up ReasFlow
To get started with ReasFlow, you need to have a basic understanding of Python programming and access to a compatible environment. You can install the required dependencies using pip:
```python
pip install reasflow
```
Once the installation is complete, you can import the ReasFlow library in your Python script:
```python
import reasflow
```
## Creating a Knowledge Graph
A knowledge graph is a crucial component of the ReasFlow system. It represents the domain knowledge and relationships between concepts. You can create a knowledge graph using the `reasflow.KnowledgeGraph` class:
```python
kg = reasflow.KnowledgeGraph()
```
You can then add nodes and edges to the knowledge graph using the `add_node` and `add_edge` methods:
```python
kg.add_node("Mathematics", "Field of study")
kg.add_node("Algebra", "Branch of mathematics")
kg.add_edge("Mathematics", "Algebra", "has_branch")
```
## Defining Agents
Agents are the core components of the ReasFlow system. They are responsible for reasoning and decision-making. You can define an agent using the `reasflow.Agent` class:
```python
agent = reasflow.Agent(kg, "Mathematics")
```
You can then specify the agent's goals and objectives using the `set_goal` method:
```python
agent.set_goal("Solve equation")
```
## Running the Simulation
Once you have defined the knowledge graph and agents, you can run the simulation using the `run_simulation` method:
```python
reasflow.run_simulation([agent], kg)
```
This will execute the simulation and produce output based on the agent's actions and decisions.

## Example Use Case
Let's consider an example use case where we want to use ReasFlow to solve a mathematical equation. We can define the knowledge graph and agents as follows:
```python
kg = reasflow.KnowledgeGraph()
kg.add_node("Equation", "Mathematical expression")
kg.add_node("Variable", "Unknown value")
kg.add_edge("Equation", "Variable", "has_variable")

agent = reasflow.Agent(kg, "Equation")
agent.set_goal("Solve equation")

reasflow.run_simulation([agent], kg)
```
This will execute the simulation and produce output based on the agent's actions and decisions.
