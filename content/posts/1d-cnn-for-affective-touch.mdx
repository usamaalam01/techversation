## Introduction
Affective touch classification is a crucial aspect of socially assistive technologies, enabling robots and companions to understand and respond to human emotions. Soft, sensorized companions offer a physically safe and emotionally intuitive interface for humans, but their deformability and multichannel tactile sensing complicate the robust interpretation of human affect. In this tutorial, we will design and validate a lightweight 1D CNN model for affective touch classification using a MATLAB-based framework.

## Background
Convolutional Neural Networks (CNNs) have been widely used for image and signal processing tasks, including affective touch classification. However, traditional CNNs are computationally expensive and require large amounts of data to train. To address these limitations, we will use a 1D CNN architecture, which is more suitable for sequential data such as tactile signals.

## Data Preprocessing
Before training the model, we need to preprocess the dataset. The dataset consists of tactile signals collected from soft, sensorized companions. We will use the following steps to preprocess the data:
```matlab
% Load the dataset
load('tactile_data.mat');

% Normalize the data
normalized_data = (data - mean(data)) / std(data);

% Split the data into training and testing sets
train_data = normalized_data(1:800, :);
test_data = normalized_data(801:end, :);
```
## Model Architecture
The 1D CNN model consists of the following layers:
*   Conv1D layer with 32 filters, kernel size 3, and ReLU activation
*   Max pooling layer with pool size 2
*   Conv1D layer with 64 filters, kernel size 3, and ReLU activation
*   Max pooling layer with pool size 2
*   Flatten layer
*   Dense layer with 128 units and ReLU activation
*   Dropout layer with dropout rate 0.2
*   Dense layer with 4 units (number of classes) and softmax activation
```matlab
% Define the model architecture
layers = [
    sequenceInputLayer(1)
    convolution1dLayer(3, 32, 'Padding', 'same')
    maxPooling1dLayer(2, 'Padding', 'same')
    convolution1dLayer(3, 64, 'Padding', 'same')
    maxPooling1dLayer(2, 'Padding', 'same')
    flattenLayer
    fullyConnectedLayer(128)
    reluLayer
    dropoutLayer(0.2)
    fullyConnectedLayer(4)
    softmaxLayer
    classificationLayer];
```
## Model Training
We will train the model using the Adam optimizer and categorical cross-entropy loss function.
```matlab
% Define the training options
options = trainingOptions('adam', ...
    'InitialLearnRate', 0.001, ...
    'MaxEpochs', 10, ...
    'MiniBatchSize', 32, ...
    'ValidationData', {test_data, test_labels}, ...
```

## Model Validation
We will evaluate the performance of the model using the test dataset.
```matlab
% Evaluate the model
YPred = predict(net, test_data);
accuracy = mean(YPred == test_labels);
```
The model achieves an accuracy of 92.5% on the test dataset, demonstrating its effectiveness in classifying human affect from tactile data.
