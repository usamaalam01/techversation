## What is Differential Privacy?
Differential privacy is a mathematical framework for protecting individual data in statistical analyses. It works by adding noise to the data, making it difficult for attackers to infer sensitive information about individuals. This approach has been widely adopted in various fields, including census data collection, to ensure the confidentiality of respondents' information. For example, the US Census Bureau has used differential privacy to protect the data collected during the 2020 census.

```python
import numpy as np

# Simulate a simple differential privacy mechanism
def add_noise(data, epsilon):
    noise = np.random.laplace(0, 1/epsilon, size=len(data))
    return data + noise

# Example usage
data = np.array([1, 2, 3, 4, 5])
epsilon = 1.0
noisy_data = add_noise(data, epsilon)
print(noisy_data)
```
