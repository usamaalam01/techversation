## Introduction to the Vulnerability

A recent update to Chromium, version 148, has introduced a surprising vulnerability that allows websites to fingerprint the underlying operating system using the `Math.tanh` function. This news, [first reported on Scrapfly](https://scrapfly.dev/posts/browser-math-os-fingerprint/), has raised concerns about user privacy and security. In this post, we'll delve into what happened, why it matters to developers, and the broader implications of this update.

## What Happened?

The `Math.tanh` function, used for calculating the hyperbolic tangent of a number, has been found to behave slightly differently across various operating systems. This difference in behavior can be exploited by websites to determine the underlying OS of a visitor's device. The vulnerability is not a result of a bug in the `Math.tanh` function itself but rather a consequence of how different operating systems handle the calculation of this mathematical function.

```javascript
// Example of using Math.tanh
const result = Math.tanh(1);
console.log(result);
```

The discrepancy in results, although minor, can be used to create a fingerprint that identifies the operating system. This fingerprinting technique can potentially be used to track users across the web, undermining their privacy.
