## Introduction

Large language models (LLMs) have become increasingly popular in recent years due to their impressive performance on a wide range of natural language processing tasks. However, concerns about fairness and bias in these models have also grown. Recent studies have shown that instruction-tuned LLMs can exhibit behavioral fairness in high-stakes decisions, such as predicting loan eligibility or job candidate suitability, while retaining biased associations in their internal representations.

In this tutorial, we will investigate the causal potency and asymmetry of latent bias in LLMs. We will explore the use of causal science to analyze the internal representations of LLMs and provide practical code examples to demonstrate the concepts.

## Understanding Causal Potency and Asymmetry

Causal potency refers to the ability of a variable to affect the outcome of a decision-making process. In the context of LLMs, causal potency refers to the ability of biased internal representations to affect the model's outputs. Asymmetry, on the other hand, refers to the idea that the causal potency of biased internal representations may vary across different demographic groups.

To investigate the causal potency and asymmetry of latent bias in LLMs, we need to analyze the internal representations of these models. One way to do this is by using techniques from causal science, such as causal graphs and structural causal models.

## Analyzing Internal Representations using Causal Graphs

Causal graphs are a powerful tool for analyzing the internal representations of LLMs. A causal graph is a directed graph that represents the causal relationships between variables in a system. In the context of LLMs, a causal graph can be used to represent the relationships between the input variables, the internal representations, and the output variables.

```python
import networkx as nx
import matplotlib.pyplot as plt

# Create a causal graph
G = nx.DiGraph()
G.add_node("Input")
G.add_node("Internal Representation")
G.add_node("Output")
G.add_edge("Input", "Internal Representation")
G.add_edge("Internal Representation", "Output")

# Draw the causal graph
pos = nx.spring_layout(G)
nx.draw(G, pos, with_labels=True, node_color='skyblue', node_size=1500, edge_color='black', linewidths=1, font_size=12)
plt.show()
```

This code creates a simple causal graph with three nodes: Input, Internal Representation, and Output. The edges between the nodes represent the causal relationships between the variables.

## Investigating Causal Potency and Asymmetry

To investigate the causal potency and asymmetry of latent bias in LLMs, we need to analyze the internal representations of these models. One way to do this is by using techniques from causal science, such as causal mediation analysis.

Causal mediation analysis is a technique that allows us to analyze the causal relationships between variables in a system. In the context of LLMs, causal mediation analysis can be used to analyze the relationships between the input variables, the internal representations, and the output variables.

```python
import pandas as pd
from causalml.inference import CausalModel

# Load the data
data = pd.read_csv("data.csv")

# Create a causal model
model = CausalModel(data, treatment="Input", outcome="Output", mediators=["Internal Representation"])

# Estimate the causal effects
effects = model.estimate_effects()

# Print the results
print(effects)
```

This code loads a dataset and creates a causal model using the `CausalModel` class from the `causalml` library. The model is then used to estimate the causal effects of the input variables on the output variables, mediated by the internal representations.
