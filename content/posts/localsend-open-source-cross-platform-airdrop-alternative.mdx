## Introduction to Localsend

Localsend is a new open-source tool that allows for cross-platform file sharing, positioning itself as an alternative to Apple's AirDrop. With its cross-platform compatibility, Localsend enables users to share files between different operating systems, including Windows, macOS, and Linux. This tutorial will delve into the capabilities of Localsend, explaining how to get started and providing practical examples of its usage.

## Setting Up Localsend

To begin using Localsend, you'll need to download and install it from the official GitHub repository: https://github.com/localsend/localsend. The installation process varies depending on your operating system. For Windows and macOS, you can download the pre-built binaries, while Linux users can build it from source.

### Installing Localsend on Windows

1. Visit the Localsend GitHub repository and download the latest Windows binary.
2. Extract the downloaded archive to a directory of your choice.
3. Run the `localsend.exe` file to start the application.

### Installing Localsend on macOS

1. Download the macOS binary from the Localsend GitHub repository.
2. Open the downloaded `.dmg` file and follow the installation prompts.
3. Once installed, you can find Localsend in your Applications folder.

### Installing Localsend on Linux

To install Localsend on Linux, you'll need to build it from source. Ensure you have the necessary dependencies installed, including `git`, `cmake`, and a C++ compiler.

```bash
# Clone the Localsend repository
git clone https://github.com/localsend/localsend.git

# Change into the repository directory
cd localsend

# Build Localsend
cmake .
make

# Install Localsend
sudo make install
```

## Using Localsend

Once installed, you can launch Localsend and start sharing files. The interface is straightforward, allowing you to select files to share and view nearby devices.

### Sharing Files with Localsend

To share a file using Localsend:

1. Launch the Localsend application.
2. Click on the "Share File" button.
3. Select the file you wish to share.
4. Choose the nearby device you want to share the file with.

### Receiving Files with Localsend

To receive a file using Localsend:

1. Ensure Localsend is running on the recipient device.
2. On the sender's device, select the file to share and choose the recipient's device.
3. On the recipient's device, you will receive a notification prompting you to accept or decline the file transfer.

## Programmatic Usage of Localsend

Localsend provides a command-line interface (CLI) for programmatically sharing files. This can be useful for automating file transfers or integrating Localsend into scripts.

### Sharing Files Using the Localsend CLI

To share a file using the Localsend CLI:

```bash
# Share a file
localsend share /path/to/file.txt
```

### Receiving Files Using the Localsend CLI

To receive a file using the Localsend CLI:

```bash
# Start Localsend in receive mode
localsend receive
```
