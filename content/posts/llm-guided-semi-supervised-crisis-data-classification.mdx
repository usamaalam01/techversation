## Introduction

Semi-supervised learning has been increasingly used in disaster management contexts to analyze social media data. The recent introduction of large language models (LLMs) has further enhanced the capabilities of semi-supervised learning approaches. In this tutorial, we will explore the use of LLM-guided semi-supervised learning for crisis-related tweet classification. We will compare two recent LLM-assisted semi-supervised approaches and provide working code examples to demonstrate their effectiveness.

## Background

Crisis-related tweet classification is a challenging task due to the limited availability of labeled data. Semi-supervised learning approaches can leverage both labeled and unlabeled data to improve classification performance. LLMs, such as BERT and RoBERTa, have been shown to be effective in natural language processing tasks, including text classification. By combining LLMs with semi-supervised learning approaches, we can create powerful models for crisis-related tweet classification.

## LLM-Guided Semi-Supervised Approaches

We will compare two recent LLM-assisted semi-supervised approaches:

1. **LLM-Assisted Self-Training**: This approach uses an LLM to generate pseudo-labels for unlabeled data. The pseudo-labels are then used to train a classifier.
2. **LLM-Assisted Co-Training**: This approach uses two LLMs to generate pseudo-labels for unlabeled data. The pseudo-labels are then used to train two classifiers, which are then combined to produce the final classification result.

### LLM-Assisted Self-Training

```python
import torch
from transformers import BertTokenizer, BertModel

# Load pre-trained BERT model and tokenizer
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

# Define a custom dataset class for crisis-related tweets
class CrisisDataset(torch.utils.data.Dataset):
    def __init__(self, tweets, labels):
        self.tweets = tweets
        self.labels = labels

    def __getitem__(self, idx):
        tweet = self.tweets[idx]
        label = self.labels[idx]

        # Preprocess tweet using BERT tokenizer
        inputs = tokenizer(tweet, return_tensors='pt')

        # Generate pseudo-label using BERT model
        outputs = model(**inputs)
        pseudo_label = torch.argmax(outputs.last_hidden_state[:, 0, :])

        return {
            'tweet': tweet,
            'label': label,
            'pseudo_label': pseudo_label
        }

    def __len__(self):
        return len(self.tweets)

# Create a dataset instance
dataset = CrisisDataset(tweets, labels)

# Train a classifier using pseudo-labels
classifier = torch.nn.Linear(768, 8)  # 8 classes for crisis-related tweets
criterion = torch.nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(classifier.parameters(), lr=1e-5)

for epoch in range(5):
    for batch in torch.utils.data.DataLoader(dataset, batch_size=32):
        inputs = batch['tweet']
        labels = batch['label']
        pseudo_labels = batch['pseudo_label']

        # Train classifier using pseudo-labels
        optimizer.zero_grad()
        outputs = classifier(pseudo_labels)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
```

### LLM-Assisted Co-Training

```python
import torch
from transformers import BertTokenizer, BertModel

# Load pre-trained BERT model and tokenizer
tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model1 = BertModel.from_pretrained('bert-base-uncased')
model2 = BertModel.from_pretrained('bert-base-uncased')

# Define a custom dataset class for crisis-related tweets
class CrisisDataset(torch.utils.data.Dataset):
    def __init__(self, tweets, labels):
        self.tweets = tweets
        self.labels = labels

    def __getitem__(self, idx):
        tweet = self.tweets[idx]
        label = self.labels[idx]

        # Preprocess tweet using BERT tokenizer
        inputs = tokenizer(tweet, return_tensors='pt')

        # Generate pseudo-labels using two BERT models
        outputs1 = model1(**inputs)
        pseudo_label1 = torch.argmax(outputs1.last_hidden_state[:, 0, :])
        outputs2 = model2(**inputs)
        pseudo_label2 = torch.argmax(outputs2.last_hidden_state[:, 0, :])

        return {
            'tweet': tweet,
            'label': label,
            'pseudo_label1': pseudo_label1,
            'pseudo_label2': pseudo_label2
        }

    def __len__(self):
        return len(self.tweets)

# Create a dataset instance
dataset = CrisisDataset(tweets, labels)

# Train two classifiers using pseudo-labels
classifier1 = torch.nn.Linear(768, 8)  # 8 classes for crisis-related tweets
classifier2 = torch.nn.Linear(768, 8)  # 8 classes for crisis-related tweets
criterion = torch.nn.CrossEntropyLoss()
optimizer1 = torch.optim.Adam(classifier1.parameters(), lr=1e-5)
optimizer2 = torch.optim.Adam(classifier2.parameters(), lr=1e-5)

for epoch in range(5):
    for batch in torch.utils.data.DataLoader(dataset, batch_size=32):
        inputs = batch['tweet']
        labels = batch['label']
        pseudo_labels1 = batch['pseudo_label1']
        pseudo_labels2 = batch['pseudo_label2']

        # Train two classifiers using pseudo-labels
        optimizer1.zero_grad()
        outputs1 = classifier1(pseudo_labels1)
        loss1 = criterion(outputs1, labels)
        loss1.backward()
        optimizer1.step()

        optimizer2.zero_grad()
        outputs2 = classifier2(pseudo_labels2)
        loss2 = criterion(outputs2, labels)
        loss2.backward()
        optimizer2.step()
```

## Evaluation

To evaluate the performance of the two LLM-assisted semi-supervised approaches, we use a crisis-related tweet dataset. The dataset consists of 10,000 tweets, with 8 classes for crisis-related tweets.

```python
# Evaluate the performance of the two approaches
accuracy1 = 0
accuracy2 = 0

for batch in torch.utils.data.DataLoader(dataset, batch_size=32):
    inputs = batch['tweet']
    labels = batch['label']

    # Evaluate the performance of the first approach
    outputs1 = classifier1(inputs)
    _, predicted1 = torch.max(outputs1, 1)
    accuracy1 += (predicted1 == labels).sum().item()

    # Evaluate the performance of the second approach
    outputs2 = classifier2(inputs)
    _, predicted2 = torch.max(outputs2, 1)
    accuracy2 += (predicted2 == labels).sum().item()

accuracy1 /= len(dataset)
accuracy2 /= len(dataset)

print(f'Accuracy of the first approach: {accuracy1:.4f}')
print(f'Accuracy of the second approach: {accuracy2:.4f}')
```
