## Introduction
Microsoft has recently open-sourced a new tool called pg_durable, which provides in-database durable execution for PostgreSQL databases. This tool is designed to ensure that database transactions are executed reliably and durably, even in the event of failures or errors. In this tutorial, we will take a closer look at pg_durable and how it can be used to improve the reliability and durability of database transactions.

## What is pg_durable?
pg_durable is a PostgreSQL extension that provides a way to execute database transactions durably. It does this by using a combination of logging and checkpointing to ensure that transactions are executed reliably and consistently, even in the event of failures or errors. pg_durable is designed to be simple and efficient, making it easy to integrate into existing database applications.

## Getting Started with pg_durable
To get started with pg_durable, you will need to install the PostgreSQL database management system and the pg_durable extension. You can download the pg_durable extension from the [Microsoft GitHub repository](https://github.com/microsoft/pg_durable).

Once you have installed the pg_durable extension, you can enable it in your PostgreSQL database by running the following command:
```sql
CREATE EXTENSION pg_durable;
```
This will create the necessary tables and functions to support durable execution in your database.

## Using pg_durable
To use pg_durable, you will need to create a durable execution context. This can be done using the `BEGIN DURABLE` command, like this:
```sql
BEGIN DURABLE;
```
This will start a new durable execution context, which will ensure that all subsequent transactions are executed durably.

To execute a transaction durably, you can use the `COMMIT DURABLE` command, like this:
```sql
COMMIT DURABLE;
```
This will commit the current transaction and ensure that it is executed durably.

## Example Use Case
Here is an example use case that demonstrates how to use pg_durable to execute a database transaction durably:
```sql
-- Create a sample table
CREATE TABLE sample_table (
    id SERIAL PRIMARY KEY,
    name VARCHAR(50)

-- Start a durable execution context
BEGIN DURABLE;

-- Insert a new row into the sample table
INSERT INTO sample_table (name) VALUES ('John Doe');

-- Commit the transaction durably
```
