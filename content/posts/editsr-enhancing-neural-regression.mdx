## Introduction to EditSR
Neural symbolic regression models have improved inference efficiency by shifting structural search to pretraining. However, their one-pass autoregressive decoding is prone to error accumulation, leading to structurally incorrect expressions. EditSR, introduced in the paper [EditSR: Enhancing Neural Symbolic Regression via Edit-based Rectification](https://arxiv.org/abs/2606.07915), is a new rectification strategy that alleviates this issue.

### What is EditSR?
EditSR is an edit-based rectification strategy that improves the decoding process in neural symbolic regression models. It works by identifying and correcting errors in the generated expressions, reducing error accumulation and improving the overall accuracy of the model.

class Dataset(torch.utils.data.Dataset):
    def __init__(self, input_dim, output_dim):
        self.input_dim = input_dim
        self.output_dim = output_dim
        self.data = []

    def __len__(self):
        return len(self.data)

    def __getitem__(self, index):
        x = torch.randn(self.input_dim)
        y = torch.randn(self.output_dim)
        return x, y

# Create the dataset and data loader

data_loader = torch.utils.data.DataLoader(dataset, batch_size=32, shuffle=True)

# Train the model
model = EditSR(2, 1)
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

for epoch in range(100):
    for x, y in data_loader:
        # Forward pass
        output = model(x)
        
        # Edit the generated expressions
        edited_output = model.edit(output, y)
        
        # Calculate the loss
        loss = criterion(edited_output, y)
        
        # Backward pass
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    
    print(f'Epoch {epoch+1}, Loss: {loss.item()}')
