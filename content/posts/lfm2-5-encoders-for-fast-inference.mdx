## Introduction to LFM2.5 Encoders
LFM2.5 encoders, introduced by the Hugging Face team, are designed to accelerate long-context inference on CPU. These encoders are particularly useful in applications where computational resources are limited, and fast inference times are crucial. In this tutorial, we will explore how to use LFM2.5 encoders with the Hugging Face library to achieve significant speedups in inference times without sacrificing model accuracy.

## Installing the Required Libraries
To get started with LFM2.5 encoders, you need to install the Hugging Face library. You can do this by running the following command in your terminal:
```bash
pip install transformers
```
Once the installation is complete, you can import the required libraries in your Python script:
```python
import torch
from transformers import LFM2_5EncoderForCausalLM, LFM2_5Tokenizer
```
## Loading the LFM2.5 Encoder Model
To use the LFM2.5 encoder, you need to load the pre-trained model and tokenizer. You can do this using the following code:
```python
model = LFM2_5EncoderForCausalLM.from_pretrained("lfm2-5-encoder")
tokenizer = LFM2_5Tokenizer.from_pretrained("lfm2-5-encoder")
```
## Encoding Text with LFM2.5 Encoders
To encode text using the LFM2.5 encoder, you can use the `encode` method of the tokenizer. Here's an example:
```python
input_text = "This is an example sentence."
inputs = tokenizer(input_text, return_tensors="pt")
```
## Inference with LFM2.5 Encoders
To perform inference with the LFM2.5 encoder, you can use the `generate` method of the model. Here's an example:
```python
output = model.generate(**inputs)
```
The `generate` method returns a tensor containing the encoded output.

### Measuring Inference Time
To measure the inference time, you can use the `time` library in Python. Here's an example:
```python
import time

start_time = time.time()
output = model.generate(**inputs)
end_time = time.time()

inference_time = end_time - start_time
print(f"Inference time: {inference_time:.2f} seconds")
```
This code measures the time it takes to perform inference with the LFM2.5 encoder.
