## Introduction
Text enrichment is a crucial task in natural language processing (NLP) that involves extracting relevant information from unstructured text data. However, high-volume structured extraction can be computationally expensive and time-consuming, especially when using large models. To address this issue, researchers have proposed the concept of sub-1B on-device distillation, which involves distilling the knowledge of a large model into a smaller, more efficient model that can run on-device.

## Background
The concept of sub-1B on-device distillation is based on the idea of knowledge distillation, which involves transferring the knowledge of a large model (the "teacher") to a smaller model (the "student"). The goal of knowledge distillation is to preserve the performance of the large model while reducing the computational cost and memory requirements of the smaller model.

The sub-1B on-device distillation technique is specifically designed for structured text enrichment tasks, where the input text is mapped to a JSON object with a short summary and five categoric labels. The technique involves distilling the knowledge of a large model into a smaller model that can run on-device, reducing the latency and computational cost of the text enrichment task.

## Distillation Process
The distillation process involves the following steps:

1. **Teacher Model Training**: Train a large model (the "teacher") on the structured text enrichment task. The teacher model should be trained on a large dataset and should achieve high performance on the task.
2. **Student Model Initialization**: Initialize a smaller model (the "student") with a similar architecture to the teacher model. The student model should have fewer parameters and should be designed to run on-device.
3. **Distillation**: Use the teacher model to generate soft labels for the training data. The soft labels should reflect the confidence of the teacher model in its predictions.
4. **Student Model Training**: Train the student model on the training data using the soft labels generated by the teacher model. The student model should be trained to minimize the difference between its predictions and the soft labels.
