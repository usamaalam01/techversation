## Introduction
CRADIPOR is a numerical dispersion prediction tool for automotive crash simulations. It is designed to work with finite element (FE) crash models, which are widely used throughout vehicle development. However, the predictions of these models are not strictly repeatable due to parallel computation and model complexity. CRADIPOR aims to address this issue by providing a reliable and efficient way to predict dispersion in crash simulations.

## Installing CRADIPOR
To get started with CRADIPOR, you need to install it on your system. CRADIPOR is available on GitHub, and you can install it using pip:
```bash
pip install cradipor
```
Once installed, you can import CRADIPOR in your Python script:
```python
import cradipor
```
## Basic Usage
CRADIPOR provides a simple and intuitive API for predicting dispersion in crash simulations. Here is an example of how to use CRADIPOR:
```python
# Import CRADIPOR
import cradipor

# Load the finite element crash model
model = cradipor.load_model('path/to/model')

# Set the simulation parameters
params = cradipor.SimulationParams(
    velocity=50,  # km/h
    angle=30,  # degrees
    soil_type='clay'
)

# Run the simulation
simulation = cradipor.run_simulation(model, params)

# Predict the dispersion
dispersion = cradipor.predict_dispersion(simulation)

# Print the results
print(dispersion)
```
This code loads a finite element crash model, sets the simulation parameters, runs the simulation, and predicts the dispersion.

## Advanced Usage
CRADIPOR also provides advanced features for customizing the simulation and prediction process. For example, you can specify the numerical method used for the simulation:
```python
# Set the numerical method
params.numerical_method = 'finite_difference'

# Run the simulation
simulation = cradipor.run_simulation(model, params)
```
You can also specify the type of dispersion prediction:
```python
# Set the dispersion prediction type
params.dispersion_type = 'gaussian'

# Predict the dispersion
dispersion = cradipor.predict_dispersion(simulation)
```
## Working with Finite Element Models
CRADIPOR supports a variety of finite element models, including Abaqus, Nastran, and LS-DYNA. To load a finite element model, you can use the `load_model` function:
```python
# Load the finite element model
model = cradipor.load_model('path/to/model.inp')
```
You can also create a finite element model from scratch using the `create_model` function:
```python
# Create a new finite element model
model = cradipor.create_model(
    nodes=[(0, 0, 0), (1, 0, 0), (1, 1, 0)],
    elements=[(0, 1, 2)],
    materials=[{'name': 'steel', 'density': 7850}]
)
```
## Visualizing the Results
CRADIPOR provides a variety of tools for visualizing the results of the simulation and prediction. For example, you can use the `plot_simulation` function to plot the simulation results:
```python
# Plot the simulation results
cradipor.plot_simulation(simulation)
```
You can also use the `plot_dispersion` function to plot the dispersion prediction:
```python
# Plot the dispersion prediction
cradipor.plot_dispersion(dispersion)
```
