## Introduction

Building a modern document application requires a lot of effort and resources, especially when it comes to designing and implementing the user interface. To simplify this process, the team at Extend AI has released an open-source UI kit called Extend UI. In this tutorial, we will take a closer look at Extend UI and explore how to use it to build a sample document application.

## What is Extend UI?

Extend UI is a comprehensive UI kit that provides a set of pre-built UI components, including buttons, inputs, navigation menus, and more. It is designed to help developers create consistent and intuitive user interfaces for their document applications. Extend UI is built using modern web technologies, including HTML, CSS, and JavaScript, and is fully customizable to fit the needs of your application.

## Getting Started with Extend UI

To get started with Extend UI, you can visit the official website at [https://www.extend.ai/ui](https://www.extend.ai/ui) and download the UI kit. The kit includes a range of pre-built components, as well as a set of tools and resources to help you get started.

### Installing Extend UI

To install Extend UI, you can use npm or yarn by running the following command:
```bash
npm install @extend-ui/core
```
or
```bash
yarn add @extend-ui/core
```
This will install the core Extend UI package and its dependencies.

### Importing Extend UI Components

To use Extend UI components in your application, you need to import them into your JavaScript file. For example:
```javascript
import { Button, Input } from '@extend-ui/core';
```
This imports the `Button` and `Input` components from the `@extend-ui/core` package.

## Building a Sample Document App

To demonstrate how to use Extend UI, let's build a sample document application. Our application will have a simple layout with a navigation menu, a document editor, and a toolbar.

### Creating the Navigation Menu

To create the navigation menu, we can use the `Navigation` component from Extend UI. Here's an example:
```javascript
import { Navigation } from '@extend-ui/core';

const navigation = (
  <Navigation>
    <Navigation.Item>File</Navigation.Item>
    <Navigation.Item>Edit</Navigation.Item>
    <Navigation.Item>View</Navigation.Item>
  </Navigation>
);
```
This creates a basic navigation menu with three items: File, Edit, and View.

### Creating the Document Editor

To create the document editor, we can use a simple `textarea` element. Here's an example:
```javascript
import { Input } from '@extend-ui/core';

const editor = (
  <Input
    type="textarea"
    placeholder="Enter your text here..."
    rows={10}
    cols={50}
  />
);
```
This creates a basic text area with a placeholder text and a fixed size.

### Creating the Toolbar

To create the toolbar, we can use a combination of `Button` and `Input` components from Extend UI. Here's an example:
```javascript
import { Button, Input } from '@extend-ui/core';

const toolbar = (
  <div>
    <Button>Save</Button>
    <Button>Print</Button>
    <Input type="search" placeholder="Search..." />
  </div>
);
```
This creates a basic toolbar with two buttons (Save and Print) and a search input field.

### Putting it all Together

To put all the components together, we can create a simple layout using HTML and CSS. Here's an example:
```html
<div className="app-container">
  <div className="navigation-menu">{navigation}</div>
  <div className="document-editor">{editor}</div>
  <div className="toolbar">{toolbar}</div>
</div>
```
This creates a basic layout with a navigation menu, a document editor, and a toolbar.
