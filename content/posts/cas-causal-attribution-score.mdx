## Introduction to Causal Attribution Score (CAS)

The Causal Attribution Score (CAS) is a novel approach to explainable artificial intelligence (AI). It introduces a compact score architecture for causal explanation, which allocates the joint intervention contrast with an identified interventional coalition game. In this tutorial, we will delve into the world of CAS and explore its applications in local and global explainable AI.

### What is Causal Attribution Score (CAS)?

CAS is a method for attributing the outcome of a model to specific input features. It starts from an identified interventional coalition game and allocates the joint intervention contrast with the intervention effects on the real-world outcome. This approach enables us to understand how the model's output is affected by individual input features.

## Implementing CAS

To implement CAS, we need to follow these steps:

1. **Define the model**: We start by defining a machine learning model that we want to explain. This can be any type of model, such as a neural network or a decision tree.
2. **Identify the interventional coalition game**: We need to identify the interventional coalition game, which is a set of rules that define how the input features interact with each other.
3. **Allocate the joint intervention contrast**: We allocate the joint intervention contrast with the intervention effects on the real-world outcome.

Let's consider an example to illustrate this process. Suppose we have a model that predicts the probability of a customer buying a product based on their age, income, and location.
