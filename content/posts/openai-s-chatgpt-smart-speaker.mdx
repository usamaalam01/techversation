## Getting Started with ChatGPT API

To get started with the ChatGPT API, developers need to create an account on the OpenAI platform and obtain an API key. The API key will be used to authenticate requests to the ChatGPT API.

```python
import os
import requests

# Set API key
api_key = os.environ.get("OPENAI_API_KEY")

# Set API endpoint
endpoint = "https://api.openai.com/v1/chat/completions"

# Set API parameters
params = {
    "model": "chat-gpt",
    "prompt": "Hello, how are you?",
    "temperature": 0.7,
    "max_tokens": 1024,
    "top_p": 1,
    "frequency_penalty": 0,
    "presence_penalty": 0
}

# Set API headers
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

# Send API request
response = requests.post(endpoint, headers=headers, json=params)

# Print API response
print(response.json())
```

## Building a Smart Speaker Application

To build a smart speaker application that integrates with ChatGPT, developers can use a combination of natural language processing (NLP) and machine learning (ML) techniques. The application will need to handle voice commands, process the audio input, and send the text transcription to the ChatGPT API for processing.

```python
import speech_recognition as sr
import pyaudio

# Set up speech recognition
r = sr.Recognizer()

# Set up audio input
with sr.Microphone() as source:
    print("Please say something:")
    audio = r.listen(source)

# Transcribe audio input
try:
    text = r.recognize_google(audio)
    print("You said: " + text)
except sr.UnknownValueError:
    print("Could not understand audio")
except sr.RequestError as e:
    print("Could not request results; {0}".format(e))
```

## Integrating with ChatGPT API

Once the audio input has been transcribed, the text can be sent to the ChatGPT API for processing. The API will respond with a text output, which can then be converted back to speech using a text-to-speech (TTS) library.

```python
import pyttsx3

# Set up TTS engine
engine = pyttsx3.init()

# Set API response
api_response = response.json()["choices"][0]["text"]

# Convert API response to speech
engine.say(api_response)
engine.runAndWait()
```
