## Introduction
With the increasing concern about privacy and security, many homeowners are looking for ways to secure their homes without compromising their personal data. Secluso is an open-source private home security camera system that provides end-to-end encryption, ensuring that your video feeds are secure and private. In this tutorial, we will guide you through setting up and using Secluso.

## Setting up Secluso
To get started with Secluso, you will need to install the core software on your system. You can find the installation instructions on the [Secluso GitHub page](https://github.com/secluso/core). Once you have installed the software, you can configure your camera settings and start streaming your video feeds.

### Installing Secluso
To install Secluso, you can use the following command:
```bash
git clone https://github.com/secluso/core.git
cd core
pip install -r requirements.txt
```
This will install all the necessary dependencies and get you started with Secluso.

## Configuring Camera Settings
Once you have installed Secluso, you can configure your camera settings using the web interface. To access the web interface, navigate to `http://localhost:8080` in your web browser. You will be prompted to create a username and password for your account.

### Creating a New User
To create a new user, use the following Python code:
```python
import requests

url = "http://localhost:8080/api/users"
data = {
    "username": "your_username",
    "password": "your_password"
}

response = requests.post(url, json=data)

if response.status_code == 201:
    print("User created successfully")
else:
    print("Failed to create user")
```
This will create a new user with the specified username and password.

## Streaming Video Feeds
To stream your video feeds, you can use the Secluso API. You can use the following Python code to stream your video feeds:
```python
import cv2
import requests

url = "http://localhost:8080/api/stream"
response = requests.get(url, stream=True)

while True:
    frame = response.raw.read(1024)
    if not frame:
        break

    cv2.imshow("Video Feed", frame)

        break

```
This will stream your video feed and display it in a window.
