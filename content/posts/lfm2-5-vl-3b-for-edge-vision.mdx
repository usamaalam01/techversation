## Implementing LFM2.5-VL-3B

Now that we have the model and tokenizer installed, let's implement a simple image classification task using LFM2.5-VL-3B. We'll use the following code:
```python
import torch
from PIL import Image
from transformers import AutoModel, AutoTokenizer

# Load the model and tokenizer
model_name = "LiquidAI/lfm2.5-vl-3b"
model = AutoModel.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)

# Load the image
image = Image.open("image.jpg")

# Preprocess the image
inputs = tokenizer(image, return_tensors="pt")

# Forward pass
outputs = model(**inputs)

# Get the classification output
classification_output = outputs.last_hidden_state[:, 0, :]

# Print the classification output
print(classification_output)
```
This code loads the LFM2.5-VL-3B model and tokenizer, loads an image, preprocesses the image, and performs a forward pass to get the classification output.
