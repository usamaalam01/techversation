## Introduction
Large language models (LLMs) have revolutionized the field of natural language processing, and prompting has emerged as a key technique to steer their behavior. However, the inner workings of prompting remain unclear, making it challenging to understand how instruction changes reshape internal representations to produce behavior. Recently, a new framework has been proposed to decompose prompting into a transformation of the representational geometry of the content. In this tutorial, we will delve into the concept of decomposing prompting behavior and provide concrete code examples to demonstrate its application.

## Background
The concept of prompting is based on the idea that a well-crafted input prompt can guide the model to produce a specific output. However, the relationship between the prompt and the model's internal representations is not well understood. The proposed framework treats prompting as a transformation of the representational geometry of the content, which allows for a more nuanced understanding of how prompts steer behavior.

## Nested Geometric Decomposition Framework
The nested geometric decomposition framework is based on the idea of representing the model's internal state as a geometric object. The framework consists of three main components:

*   **Representation**: The model's internal state is represented as a geometric object, such as a vector or a matrix.
*   **Transformation**: The prompt is applied to the representation, transforming it into a new geometric object.
*   **Decomposition**: The transformed representation is decomposed into its constituent parts, allowing for a more nuanced understanding of how the prompt steers behavior.

### Applying the Framework
To apply the framework, we need to define a representation, transformation, and decomposition function. Let's consider a simple example using Python:

```python
import numpy as np

# Define the representation function
def representation(input_text):
    # Convert the input text to a vector representation
    vector = np.array([ord(c) for c in input_text])
    return vector

# Define the transformation function
def transformation(prompt, representation):
    # Apply the prompt to the representation
    transformed_representation = representation + np.array([ord(c) for c in prompt])
    return transformed_representation

# Define the decomposition function
def decomposition(transformed_representation):
    # Decompose the transformed representation into its constituent parts
    decomposition = np.array([np.mean(transformed_representation[:i+1]) for i in range(len(transformed_representation))])
    return decomposition

# Apply the framework
input_text = "Hello World"
prompt = "How are you?"
representation_vector = representation(input_text)
transformed_representation = transformation(prompt, representation_vector)
decomposition_vector = decomposition(transformed_representation)

print("Representation Vector:", representation_vector)
print("Transformed Representation:", transformed_representation)
print("Decomposition Vector:", decomposition_vector)
```

This code defines a simple representation, transformation, and decomposition function, and applies the framework to an example input text and prompt.
