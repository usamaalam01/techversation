## Introduction to Mike

Mike is an open-source legal AI tool that aims to automate legal tasks and provide insights to legal professionals. It's a promising tool that can help streamline legal workflows and reduce the burden of manual tasks. In this tutorial, we'll explore Mike's features and capabilities, and provide a hands-on guide on how to get started with it.

## Setting Up Mike

To get started with Mike, you'll need to visit the [Mike website](https://mikeoss.com/) and follow the installation instructions. Mike provides a range of installation options, including Docker and GitHub repositories. For this tutorial, we'll use the Docker installation method.

```bash
# Pull the Mike Docker image
docker pull mikeoss/mike

# Run the Mike Docker container
docker run -p 8080:8080 mikeoss/mike
```

Once you've installed Mike, you can access the web interface by navigating to `http://localhost:8080` in your web browser.

## Using Mike for Document Analysis

One of Mike's key features is its document analysis capability. You can upload a document to Mike, and it will provide insights and summaries of the content. To demonstrate this feature, let's upload a sample document to Mike.

```python
# Import the required libraries
import requests

# Set the Mike API endpoint and authentication token
mike_api_endpoint = "http://localhost:8080/api/v1/documents"
auth_token = "your_auth_token"

# Set the document file path and name
document_file_path = "/path/to/your/document.pdf"
document_name = "sample_document.pdf"

# Upload the document to Mike
with open(document_file_path, "rb") as document_file:
    response = requests.post(
        mike_api_endpoint,
        headers={"Authorization": f"Bearer {auth_token}"},
        files={"document": (document_name, document_file)},
    )

# Print the response from Mike
print(response.json())
```

This code snippet demonstrates how to upload a document to Mike using the API. You'll need to replace `your_auth_token` with your actual authentication token, which can be obtained by registering for a Mike account.
