## Introduction

ReAct-style LLM agents have shown impressive capabilities in solving complex problems. However, these agents often rediscover the same reasoning routines across problems, only to discard them after use. To address this issue, we introduce Reasoning Primitive Induction, a single-pass method for mining successful ReAct traces, clustering recurrent reasoning moves, and converting the most frequent moves into a compact library of typed primitives.

## Background

Reasoning Primitive Induction is based on the idea that agents can learn to recognize and reuse common reasoning patterns. By analyzing agent traces, we can identify these patterns and create a library of reusable primitives. This library can be used to improve the performance of ReAct agents and reduce the computational overhead of rediscovering the same reasoning routines.

## Implementing Reasoning Primitive Induction

To implement Reasoning Primitive Induction, we will use Python and the following libraries:

* `numpy` for numerical computations
* `scipy` for clustering and distance calculations
* `pandas` for data manipulation and storage

First, we need to load the agent traces and preprocess the data. We assume that the agent traces are stored in a CSV file, where each row represents a single trace.

```python
import numpy as np
import pandas as pd
from scipy.cluster.hierarchy import linkage, fcluster

# Load the agent traces
traces = pd.read_csv('traces.csv')

# Preprocess the data
traces = traces.dropna()  # remove rows with missing values
traces = traces.apply(lambda x: x.astype(str))  # convert all columns to strings
```

Next, we need to cluster the recurrent reasoning moves. We will use hierarchical clustering with the Jaccard distance metric.

```python
# Define the Jaccard distance metric
def jaccard_distance(x, y):
    intersection = set(x) & set(y)
    union = set(x) | set(y)
    return 1 - len(intersection) / len(union)

# Calculate the distance matrix
distance_matrix = np.zeros((len(traces), len(traces)))
for i in range(len(traces)):
    for j in range(i+1, len(traces)):
        distance_matrix[i, j] = jaccard_distance(traces.iloc[i], traces.iloc[j])
        distance_matrix[j, i] = distance_matrix[i, j]

# Perform hierarchical clustering
Z = linkage(distance_matrix, method='ward')

# Form flat clusters
clusters = fcluster(Z, t=0.5, criterion='distance')
```

Finally, we need to convert the most frequent moves into a compact library of typed primitives.

```python
# Define a function to extract the most frequent moves
def extract_primitives(clusters, traces):
    primitives = []
    for cluster in set(clusters):
        cluster_traces = traces[clusters == cluster]
        most_frequent_move = cluster_traces.mode().iloc[0]
        primitives.append(most_frequent_move)
    return primitives

# Extract the primitives
primitives = extract_primitives(clusters, traces)
```
