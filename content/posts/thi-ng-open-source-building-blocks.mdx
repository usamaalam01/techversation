## Working with Thi.ng

To demonstrate the capabilities of Thi.ng, let's take a look at a simple example of generating a geometric shape using the project's JavaScript library. We'll create a basic triangle and render it using the Canvas API.

```javascript
// Import the thi.ng library
import * as thng from 'thi.ng';

// Create a new canvas element
const canvas = document.createElement('canvas');
const ctx = canvas.getContext('2d');

// Define the triangle vertices

  [0, 0],
  [100, 0],

// Create a new geometric shape using the thi.ng library

// Render the triangle using the Canvas API

  fill: 'none'
});
```
