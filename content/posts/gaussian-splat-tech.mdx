### Code Example

To give you a better understanding of how the Gaussian splat technique works, let's take a look at a simple code example in Python:
```python
import numpy as np

def gaussian_splat(x, y, sigma):
    """
    Calculate the Gaussian splat value at a given point.
    
    Parameters:
    x (float): The x-coordinate of the point.
    y (float): The y-coordinate of the point.
    sigma (float): The standard deviation of the Gaussian distribution.
    
    Returns:
    float: The Gaussian splat value at the given point.
    """
    return np.exp(-((x**2 + y**2) / (2 * sigma**2)))

# Example usage:
x = 1.0
y = 2.0
sigma = 1.5

splat_value = gaussian_splat(x, y, sigma)
print(splat_value)
```
