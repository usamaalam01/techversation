## Introduction
DreamProver is a novel framework that leverages a wake-sleep program induction paradigm to discover reusable lemmas for formal theorem proving. In this tutorial, we will delve into the world of DreamProver and explore its capabilities. We will start with the basics of DreamProver, its architecture, and then provide working code examples to get you started.

## Background
Formal theorem proving is a crucial aspect of artificial intelligence, as it enables machines to reason and prove mathematical statements. However, existing approaches to formal theorem proving often rely on fixed lemma libraries, which limit adaptability, or synthesize highly specific intermediate lemmas tailored to individual theorems, thereby lacking generalizability. DreamProver addresses these limitations by introducing a wake-sleep program induction paradigm to discover reusable lemmas.

## DreamProver Architecture
The DreamProver framework consists of two primary components: the wake agent and the sleep agent. The wake agent is responsible for exploring the search space of possible lemmas, while the sleep agent refines and generalizes the discovered lemmas. The wake-sleep paradigm allows DreamProver to iteratively refine and expand its library of reusable lemmas.

### Wake Agent
The wake agent is implemented using a reinforcement learning algorithm, which explores the search space of possible lemmas and selects the most promising ones. The wake agent receives a reward signal based on the usefulness of the discovered lemmas.

### Sleep Agent
The sleep agent is responsible for refining and generalizing the discovered lemmas. It uses a generative model to generate new lemmas based on the patterns learned from the wake agent.

## Basic Usage
Once you have installed DreamProver, you can use it to discover reusable lemmas for formal theorem proving. Here is a basic example:
```python
import dreamprover

# Define the theorem to prove
theorem = "forall x, P(x) -> Q(x)"

# Create a DreamProver instance
prover = dreamprover.DreamProver()

# Discover reusable lemmas
lemmas = prover.discover_lemmas(theorem)

# Print the discovered lemmas
print(lemmas)
```
This code defines a theorem to prove and uses the `DreamProver` class to discover reusable lemmas. The `discover_lemmas` method returns a list of discovered lemmas, which can be used to prove the theorem.

## Advanced Usage
DreamProver provides several advanced features, including the ability to customize the wake and sleep agents. You can customize the wake agent by providing a custom reward function:
```python
import dreamprover

# Define the theorem to prove
theorem = "forall x, P(x) -> Q(x)"

# Create a DreamProver instance
prover = dreamprover.DreamProver()

# Define a custom reward function
def custom_reward(lemma):
    # Reward function based on the usefulness of the lemma
    return 1.0 if lemma.is_useful() else 0.0

# Discover reusable lemmas with the custom reward function
lemmas = prover.discover_lemmas(theorem, reward_function=custom_reward)

# Print the discovered lemmas
print(lemmas)
```
This code defines a custom reward function and uses it to discover reusable lemmas.
