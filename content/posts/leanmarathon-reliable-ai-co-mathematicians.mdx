## Introduction to LeanMarathon
LeanMarathon is a novel approach to reliable AI co-mathematicians through long-horizon Lean autoformalization. The core abstraction of LeanMarathon is an evolving blueprint, which is a Lean file that represents the mathematical knowledge being formalized. This blueprint is used by multiple agents to collaborate on the formalization process, ensuring that the resulting formalization is reliable and accurate.

## Setting Up LeanMarathon
To get started with LeanMarathon, you will need to install the Lean theorem prover and the LeanMarathon harness. You can install Lean using the following command:
```bash
git clone https://github.com/leanprover/lean.git
cd lean
make
```
Once Lean is installed, you can install the LeanMarathon harness using the following command:
```bash
git clone https://github.com/lean-marathon/lean-marathon.git
cd lean-marathon
make
```
## Creating a Lean File
A Lean file is a text file that contains mathematical definitions and theorems. To create a new Lean file, you can use the following command:
```bash
lean --new my_file.lean
```
This will create a new Lean file called `my_file.lean` with a basic template.

## Defining Mathematical Concepts
In Lean, mathematical concepts are defined using the `def` keyword. For example, you can define a function that adds two numbers using the following code:
```lean
def add (x : nat) (y : nat) : nat := x + y
```
This defines a function `add` that takes two natural numbers `x` and `y` and returns their sum.

## Using LeanMarathon
Once you have defined your mathematical concepts, you can use LeanMarathon to formalize them. To do this, you will need to create a new LeanMarathon project using the following command:
```bash
lean-marathon --new my_project
```
This will create a new LeanMarathon project called `my_project` with a basic template.

## Collaborating with Multiple Agents
One of the key features of LeanMarathon is its ability to collaborate with multiple agents. To add a new agent to your project, you can use the following command:
```bash
lean-marathon --add-agent my_agent
```
This will add a new agent called `my_agent` to your project.

## Formalizing Mathematical Theorems
Once you have added multiple agents to your project, you can use them to formalize mathematical theorems. To do this, you will need to define the theorem you want to formalize using the `theorem` keyword. For example, you can define the theorem that the sum of two even numbers is even using the following code:
```lean
theorem sum_of_even_numbers_is_even (x : nat) (y : nat) : even (x + y) := sorry
```
This defines a theorem that the sum of two even numbers `x` and `y` is even.

## Proving Theorems with LeanMarathon
To prove a theorem with LeanMarathon, you will need to use the `prove` command. For example, you can prove the theorem that the sum of two even numbers is even using the following command:
```bash
lean-marathon --prove my_theorem
```
This will use the multiple agents in your project to prove the theorem.
