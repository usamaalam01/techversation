## Introduction to Adaptive Optimization

Optimization is a crucial aspect of machine learning, and various techniques have been developed to improve the efficiency and effectiveness of optimization algorithms. One such technique is adaptive optimization, which involves adjusting the optimization process based on the problem's geometry. Recently, a new optimizer called Muon has been introduced, which imposes matrix-wise geometry constraints on its updates. These constraints can be unified under Linear Minimization Oracle (LMO) theory.

## Understanding Schatten-p Norms

Schatten-p Norms are a family of norms that can be used to measure the magnitude of a matrix. They are defined as the p-th root of the sum of the p-th powers of the singular values of the matrix. Schatten-p Norms have been used in various applications, including matrix completion and low-rank approximation.

```python
import numpy as np

def schatten_p_norm(matrix, p):
    """
    Calculate the Schatten-p Norm of a matrix.

    Args:
    matrix (numpy array): The input matrix.
    p (float): The value of p in the Schatten-p Norm.

    Returns:
    float: The Schatten-p Norm of the matrix.
    """
    singular_values = np.linalg.svd(matrix)[1]
    return np.power(np.sum(np.power(singular_values, p)), 1/p)
```

## Adaptive Optimization via Schatten-p Norms

The Muon optimizer uses Schatten-p Norms to impose matrix-wise geometry constraints on its updates. The basic idea is to minimize the Schatten-p Norm of the update matrix, which encourages the optimizer to update the parameters in a way that respects the geometry of the problem.

```python
import numpy as np
import torch
import torch.optim as optim

class MuonOptimizer(optim.Optimizer):
    def __init__(self, params, lr, p):
        """
        Initialize the Muon optimizer.

        Args:
        params (list): The list of parameters to optimize.
        lr (float): The learning rate.
        p (float): The value of p in the Schatten-p Norm.
        """
        self.params = params
        self.lr = lr
        self.p = p
        self.state = {}

    def step(self):
        """
        Perform a single optimization step.
        """
        for param in self.params:
            if param.grad is not None:
                grad = param.grad
                update = -self.lr * grad / schatten_p_norm(grad, self.p)
                param.data.add_(update)

# Example usage:
model = torch.nn.Linear(5, 3)
optimizer = MuonOptimizer(model.parameters(), lr=0.01, p=2)
criterion = torch.nn.MSELoss()

for epoch in range(100):
    optimizer.zero_grad()
    outputs = model(torch.randn(10, 5))
    loss = criterion(outputs, torch.randn(10, 3))
    loss.backward()
    optimizer.step()
```
