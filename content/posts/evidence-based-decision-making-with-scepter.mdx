## Introduction

Evidence-based clinical decision making requires specialists to identify, evaluate, and synthesize relevant scientific literature. However, with the vast amount of research papers being published every day, it can be challenging for clinicians to keep up with the latest findings. This is where SCEPTER (Single-Case Evidence-driven PubMed-To-Recommendation) comes in - a new tool that automates the process of identifying, evaluating, and synthesizing relevant scientific literature to provide actionable recommendations.

In this tutorial, we will show you how to use SCEPTER with Python to make evidence-based decisions. We will cover the basics of SCEPTER, its architecture, and provide a step-by-step guide on how to use it.

## What is SCEPTER?

SCEPTER is a multi-objective evidence reasoning framework that takes in a clinical question or case description as input and returns a set of relevant publications and recommendations. It uses a combination of natural language processing (NLP) and machine learning algorithms to identify, evaluate, and synthesize relevant scientific literature.

The architecture of SCEPTER consists of the following components:

* **Text Preprocessing**: This component is responsible for preprocessing the input text, including tokenization, stemming, and lemmatization.
* **Literature Retrieval**: This component retrieves relevant publications from PubMed based on the preprocessed input text.
* **Evidence Evaluation**: This component evaluates the retrieved publications based on their relevance, quality, and consistency.
* **Recommendation Generation**: This component generates recommendations based on the evaluated evidence.

## Using SCEPTER with Python

To use SCEPTER with Python, you will need to import the following libraries:
```python
import pandas as pd
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
import spacy
from scepter import SCEPTER
```
You will also need to load the SCEPTER model and dataset:
```python
scepter_model = SCEPTER.load('scepter-model.h5')
```
### Step 1: Preprocessing the Input Text

The first step is to preprocess the input text. This includes tokenization, stemming, and lemmatization. You can use the `spacy` library to perform these tasks:
```python
nlp = spacy.load('en_core_web_sm')
input_text = "What is the best treatment for diabetes?"
doc = nlp(input_text)
tokens = [token.text for token in doc]
```
### Step 2: Retrieving Relevant Publications

The next step is to retrieve relevant publications from PubMed. You can use the `scepter_model` to perform this task:
```python
publications = scepter_model.retrieve_publications(tokens)
```
### Step 3: Evaluating the Evidence

The next step is to evaluate the retrieved publications based on their relevance, quality, and consistency. You can use the `scepter_model` to perform this task:
```python
evaluated_publications = scepter_model.evaluate_evidence(publications)
```
### Step 4: Generating Recommendations

The final step is to generate recommendations based on the evaluated evidence. You can use the `scepter_model` to perform this task:
```python
recommendations = scepter_model.generate_recommendations(evaluated_publications)
```
