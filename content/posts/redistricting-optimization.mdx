## Introduction

Redistricting optimization is a practical combinatorial optimization problem that demands high-quality solutions, rapid turnaround, and flexibility to accommodate multi-criteria objectives and interactive refinement. A central challenge is the contiguity constraint: enforcing contiguity in integer-programming or heuristic search can severely shrink the feasible region. In this tutorial, we will explore the basics of redistricting optimization and provide a step-by-step guide to implementing composite-move tabu search, an effective approach to solve this problem.

## Background

Redistricting optimization is the process of dividing a geographic area into smaller regions, called districts, while satisfying certain constraints. The most common constraints are:

* **Contiguity**: Each district must be a contiguous region.
* **Population balance**: The population of each district must be roughly equal.
* **Compactness**: Each district must be compact, meaning that it should not be too elongated.

These constraints make the redistricting optimization problem a complex one, requiring high-quality solutions and rapid turnaround.

## Composite-Move Tabu Search

Composite-move tabu search is a heuristic search algorithm that combines multiple moves to explore the solution space efficiently. The basic idea is to start with an initial solution and apply a series of moves to improve the solution while avoiding getting stuck in local optima. The moves are designed to satisfy the contiguity constraint and improve the population balance and compactness of the districts.

### Implementation in Python

We will implement the composite-move tabu search algorithm in Python using the following steps:

```python
import numpy as np

def create_initial_solution(num_districts, num_precincts):
    # Create an initial solution by assigning each precinct to a district randomly
    solution = np.random.randint(0, num_districts, size=num_precincts)
    return solution

def calculate_objective(solution, precinct_populations, district_populations):
    # Calculate the objective function value for the given solution
    objective = 0
    for i in range(len(solution)):
        district = solution[i]
        objective += abs(precinct_populations[i] - district_populations[district])
    return objective

def apply_move(solution, precinct, new_district):
    # Apply a move to the solution by reassigning a precinct to a new district
    solution[precinct] = new_district
    return solution

def tabu_search(solution, precinct_populations, district_populations, num_iterations):
    # Perform tabu search to find a better solution
    best_solution = solution.copy()
    best_objective = calculate_objective(solution, precinct_populations, district_populations)
    tabu_list = []
    for _ in range(num_iterations):
        # Generate a new solution by applying a random move
        precinct = np.random.randint(0, len(solution))
        new_district = np.random.randint(0, len(district_populations))
        new_solution = apply_move(solution.copy(), precinct, new_district)
        new_objective = calculate_objective(new_solution, precinct_populations, district_populations)
        # Check if the new solution is better and not in the tabu list
        if new_objective < best_objective and new_solution.tolist() not in tabu_list:
            best_solution = new_solution
            best_objective = new_objective
            tabu_list.append(new_solution.tolist())
            if len(tabu_list) > 10:
                tabu_list.pop(0)
    return best_solution

# Example usage
num_districts = 5
num_precincts = 100
precinct_populations = np.random.randint(1, 100, size=num_precincts)
district_populations = np.random.randint(100, 1000, size=num_districts)
initial_solution = create_initial_solution(num_districts, num_precincts)
best_solution = tabu_search(initial_solution, precinct_populations, district_populations, 1000)
print(best_solution)
```

This code implements the composite-move tabu search algorithm to solve the redistricting optimization problem. The `create_initial_solution` function creates an initial solution by assigning each precinct to a district randomly. The `calculate_objective` function calculates the objective function value for the given solution. The `apply_move` function applies a move to the solution by reassigning a precinct to a new district. The `tabu_search` function performs tabu search to find a better solution.
