## Introduction

Vehicle routing problems are a classic example of optimization challenges in operations research. The goal is to find the most efficient routes for a fleet of vehicles to visit a set of locations and return to the depot. Large language models (LLMs) have shown promising results in translating natural-language optimization problems into executable solver code. However, existing data-filtering and training pipelines largely rely on objective-equivalence signals, which can be limiting for constraint-dense problems like vehicle routing.

In this tutorial, we will explore the concept of constraint injection for LLM-based optimization modeling and demonstrate how to use it to optimize vehicle routing problems. We will start by introducing the basics of vehicle routing problems and then move on to the concept of constraint injection.

## Vehicle Routing Problems

Vehicle routing problems involve finding the most efficient routes for a fleet of vehicles to visit a set of locations and return to the depot. The problem can be formulated as follows:

* We have a set of locations that need to be visited.
* We have a fleet of vehicles with limited capacity.
* Each location has a demand that needs to be fulfilled.
* The goal is to find the most efficient routes for the vehicles to visit the locations and return to the depot.

The vehicle routing problem can be modeled using the following mathematical formulation:

```python
from pulp import LpMaximize, LpProblem, lpSum, LpVariable

# Define the problem
prob = LpProblem("Vehicle_Routing", LpMaximize)

# Define the variables
x = LpVariable.dicts("x", (range(10), range(10)), 0, 1, cat="Integer")

# Define the objective function
prob += lpSum([x[i][j] for i in range(10) for j in range(10)])

# Define the constraints
for i in range(10):
    prob += lpSum([x[i][j] for j in range(10)]) <= 1
    prob += lpSum([x[j][i] for j in range(10)]) <= 1

# Solve the problem
prob.solve()
```

## Constraint Injection

Constraint injection is a technique for improving the performance of LLM-based optimization modeling. The idea is to inject constraints into the LLM that are relevant to the problem at hand. In the case of vehicle routing problems, we can inject constraints that relate to the capacity of the vehicles, the demand of the locations, and the distance between the locations.

To demonstrate the concept of constraint injection, let's consider the following example:

```python
from transformers import AutoModelForSeq2SeqLM, AutoTokenizer

# Load the LLM
model = AutoModelForSeq2SeqLM.from_pretrained("t5-base")
tokenizer = AutoTokenizer.from_pretrained("t5-base")

# Define the problem
problem = "Find the most efficient route for a vehicle to visit a set of locations and return to the depot."

# Define the constraints
constraints = [
    "The vehicle has a capacity of 10 units.",
    "The demand of each location is 2 units.",
    "The distance between each location is 10 units."
]

# Inject the constraints into the LLM
input_text = problem + " " + ". ".join(constraints)
inputs = tokenizer(input_text, return_tensors="pt")

# Generate the solution
output = model.generate(inputs["input_ids"], num_beams=4)

# Print the solution
print(tokenizer.decode(output[0], skip_special_tokens=True))
```

## Optimization Modeling

To optimize the vehicle routing problem using constraint injection, we need to define the objective function and the constraints. The objective function is to minimize the total distance traveled by the vehicles, and the constraints are the capacity of the vehicles, the demand of the locations, and the distance between the locations.

```python
from pulp import LpMinimize, LpProblem, lpSum, LpVariable

# Define the problem
prob = LpProblem("Vehicle_Routing", LpMinimize)

# Define the variables
x = LpVariable.dicts("x", (range(10), range(10)), 0, 1, cat="Integer")
y = LpVariable.dicts("y", (range(10), range(10)), 0, 1, cat="Integer")

# Define the objective function
prob += lpSum([x[i][j] * 10 for i in range(10) for j in range(10)])

# Define the constraints
for i in range(10):
    prob += lpSum([x[i][j] for j in range(10)]) <= 1
    prob += lpSum([x[j][i] for j in range(10)]) <= 1
    prob += lpSum([y[i][j] for j in range(10)]) <= 10

# Solve the problem
prob.solve()
```
