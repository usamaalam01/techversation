## Introduction
Long chain-of-thought reasoning has shown promise in improving performance on complex problems. However, it also introduces redundancy accumulation, context overflow, and error anchoring. ## Background
Traditional chain-of-thought reasoning involves a sequence of intermediate steps to arrive at a final solution. However, as the number of steps increases, the context window becomes bounded, leading to redundancy accumulation, context overflow, and error anchoring. ThinkReset addresses these limitations by introducing a reusable intermediate interface that can replace traditional discarding mechanisms.

1. **Context Encoder**: This module encodes the input context into a compact representation.

3. **Reasoning Module**: This module performs the actual reasoning using the intermediate interface.
