## Introduction

Market making is a crucial component of any financial market, providing liquidity to buyers and sellers. In perpetual futures markets, market makers face unique challenges due to the absence of expiration dates and the need to manage inventory risk. In this tutorial, we will explore a theoretical framework for optimal adaptive market making in perpetual futures markets, as outlined in the research paper [Optimal Adaptive Market Making: A Theoretical Framework for High-Yield Liquidity Provision in Perpetual Futures Markets](https://arxiv.org/abs/2607.11888).

## Theoretical Framework

The framework models the market maker's problem as a stochastic optimal control problem on a filtered probability space. The controls are adaptive bid-ask spreads and inventory hedging decisions across two exchanges. The goal is to maximize the market maker's expected utility, subject to inventory risk constraints.

### Stochastic Optimal Control Problem

The stochastic optimal control problem can be formulated as follows:

Let $X_t$ be the market maker's inventory at time $t$, and let $S_t$ be the spot price of the underlying asset at time $t$. The market maker's utility function is given by:

$$U(X_t, S_t) = -\frac{1}{2}X_t^2 - \frac{1}{2}(S_t - S_0)^2$$

where $S_0$ is the initial spot price.

The market maker's inventory dynamics are given by:

$$dX_t = \mu dt + \sigma dW_t$$

where $\mu$ is the drift term, $\sigma$ is the volatility term, and $W_t$ is a standard Brownian motion.

The market maker's objective is to maximize the expected utility over a finite time horizon $[0, T]$:

$$\max_{\pi} \mathbb{E} \left[ \int_0^T U(X_t, S_t) dt \right]$$

subject to the inventory dynamics and the constraints:

$$X_t \geq 0 \quad \text{and} \quad X_t \leq \bar{X}$$

where $\bar{X}$ is the maximum allowed inventory.

## Implementation in Python

We will implement the theoretical framework using Python. We will use the `numpy` library for numerical computations and the `scipy` library for optimization.

```python
import numpy as np
from scipy.optimize import minimize

# Define the utility function
def utility(x, s, s0):
    return -0.5 * x**2 - 0.5 * (s - s0)**2

# Define the inventory dynamics
def inventory_dynamics(x, mu, sigma, dt):
    return x + mu * dt + sigma * np.random.normal(0, 1) * np.sqrt(dt)

# Define the objective function
def objective(params, x0, s0, mu, sigma, dt, T):
    x = x0
    s = s0
    utility_value = 0
    for t in range(int(T/dt)):
        x = inventory_dynamics(x, mu, sigma, dt)
        s = s + np.random.normal(0, 1) * np.sqrt(dt)
        utility_value += utility(x, s, s0) * dt
    return -utility_value

# Define the constraints
def constraints(params, x0, s0, mu, sigma, dt, T):
    x = x0
    s = s0
    for t in range(int(T/dt)):
        x = inventory_dynamics(x, mu, sigma, dt)
        if x < 0 or x > 10:
            return False
    return True

# Define the optimization problem
def optimize(x0, s0, mu, sigma, dt, T):
    params0 = [0.1, 0.1]
    bounds = [(0, 1), (0, 1)]
    constraints_dict = ({'type': 'ineq', 'fun': lambda params: constraints(params, x0, s0, mu, sigma, dt, T)})
    result = minimize(objective, params0, args=(x0, s0, mu, sigma, dt, T), method='SLSQP', bounds=bounds, constraints=constraints_dict)
    return result.x

# Run the optimization
x0 = 0
s0 = 100
mu = 0.1
sigma = 0.1
dt = 0.01
T = 1
params_opt = optimize(x0, s0, mu, sigma, dt, T)
print(params_opt)
```
