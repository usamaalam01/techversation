Here is a simple example of how this could be implemented in Python:
```python
class User:
    def __init__(self, name, interests):
        self.name = name
        self.interests = interests

class SocialPlatform:
    def __init__(self):
        self.users = []

    def add_user(self, user):
        self.users.append(user)

    def suggest_friends(self, user):
        suggested_friends = []
        for other_user in self.users:
            if other_user != user:
                common_interests = set(user.interests) & set(other_user.interests)
                if common_interests:
                    suggested_friends.append(other_user)
        return suggested_friends

# Example usage
platform = SocialPlatform()
user1 = User("John", ["reading", "hiking"])
user2 = User("Jane", ["reading", "cooking"])
platform.add_user(user1)
platform.add_user(user2)
suggested_friends = platform.suggest_friends(user1)
for friend in suggested_friends:
    print(friend.name)
```
This code defines a simple social platform that suggests friends based on shared interests. It creates a `User` class to represent individual users and a `SocialPlatform` class to manage the users and suggest friends. The `suggest_friends` method uses set intersection to find common interests between users and suggests friends accordingly.
