## Introduction
Email marketing is a crucial aspect of any marketing strategy, and creating effective email templates is essential for capturing the attention of your audience. Recently, a new open-source email builder called Templatical was released, providing a alternative to popular tools like Beefree and Unlayer. In this tutorial, we will delve into the features and functionality of Templatical and provide a step-by-step guide on how to get started with creating custom email templates.

## Getting Started with Templatical
To start using Templatical, simply visit the [Templatical website](https://play.templatical.com) and sign up for an account. Once you have created an account, you will be taken to the dashboard where you can access the email builder.

### Creating a New Email Template
To create a new email template, click on the "Create Template" button on the dashboard. This will take you to the email builder interface, where you can start designing your template.

```html
<!-- Basic HTML structure for an email template -->
<!DOCTYPE html>
<html>
<head>
  <title>Email Template</title>
</head>
<body>
  <!-- Email content goes here -->
</body>
</html>
```

## Customizing Your Email Template
Templatical provides a range of features and tools to help you customize your email template. These include:

* Drag-and-drop functionality for adding content blocks
* A user-friendly interface for editing and styling your template
* A range of pre-built templates and layouts to get you started

### Adding Content Blocks
To add a content block to your template, simply drag and drop the block into the template area. You can then edit the content and styling of the block using the toolbar.

```css
/* Example CSS for styling an email template */
body {
  font-family: Arial, sans-serif;
  background-color: #f2f2f2;
}

h1 {
  color: #333;
  font-size: 24px;
}
```

## Advanced Features
Templatical also provides a range of advanced features, including:

* Conditional logic for dynamic content
* Integration with popular marketing automation platforms
* Support for custom fonts and typography

### Using Conditional Logic
To use conditional logic in your template, you can add a conditional statement to your content block. For example:

```javascript
// Example JavaScript for conditional logic
if (recipient.country === "USA") {
  // Display content for USA recipients
} else {
  // Display content for non-USA recipients
}
```

Templatical is a powerful and flexible open-source email builder that provides a range of features and tools for creating custom email templates.
