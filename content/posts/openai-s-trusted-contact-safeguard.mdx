## Introduction
OpenAI has introduced a new 'Trusted Contact' safeguard for ChatGPT users, expanding its efforts to protect users in cases where conversations may turn to self-harm. This feature allows users to designate a trusted contact who will be notified if the user is at risk. In this tutorial, we'll explore how this feature works and provide a hands-on review of the API.

## How it Works
The Trusted Contact safeguard uses a combination of natural language processing (NLP) and machine learning algorithms to detect when a user is at risk of self-harm. If a user is identified as being at risk, the designated trusted contact will be notified via email or SMS. The trusted contact can then reach out to the user and provide support.

## Getting Started with the API
To get started with the Trusted Contact API, you'll need to create an account on the OpenAI platform and obtain an API key. Once you have your API key, you can use the following Python code to designate a trusted contact:
```python
import requests

api_key = "YOUR_API_KEY"
user_id = "USER_ID"
trusted_contact_email = "TRUSTED_CONTACT_EMAIL"

url = f"https://api.openai.com/v1/trusted-contacts"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}
data = {
    "user_id": user_id,
    "trusted_contact_email": trusted_contact_email
}

response = requests.post(url, headers=headers, json=data)

if response.status_code == 200:
    print("Trusted contact designated successfully")
else:
    print("Error designating trusted contact")
```
## Checking the Status of a Trusted Contact
To check the status of a trusted contact, you can use the following Python code:
```python
import requests

api_key = "YOUR_API_KEY"
user_id = "USER_ID"

url = f"https://api.openai.com/v1/trusted-contacts/{user_id}"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)

if response.status_code == 200:
    print("Trusted contact status:", response.json())
else:
    print("Error checking trusted contact status")
```
