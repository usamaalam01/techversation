## Introduction to Participatory AI Mapping

Participatory AI approaches are being used in various public, civic, and humanitarian settings. However, evidence about how participation is organized remains fragmented. To address this issue, researchers have constructed an open repository and interactive atlas of participatory AI initiatives. In this tutorial, we will explore how to use this atlas to map participatory AI initiatives.

The atlas is built using records harmonized from various sources, including Maga~na. The goal of the atlas is to provide a comprehensive overview of participatory AI initiatives and to facilitate collaboration and knowledge sharing among researchers and practitioners.

## Setting Up the Atlas

To get started with the atlas, you need to have Python and the necessary libraries installed. You can install the required libraries using pip:
```python
pip install pandas matplotlib folium
```
Once you have the libraries installed, you can download the atlas data from the [arXiv repository](https://arxiv.org/abs/2605.16827). The data is available in CSV format, which can be easily imported into Python using the pandas library.

## Importing the Data

To import the data, you can use the following code:
```python
import pandas as pd

# Load the data from the CSV file
data = pd.read_csv('participatory_ai_initiatives.csv')

# Print the first few rows of the data
print(data.head())
```
This code loads the data from the CSV file and prints the first few rows of the data.

## Mapping the Initiatives

To map the initiatives, you can use the folium library. Folium is a Python library that allows you to create interactive maps. You can use the following code to create a map of the initiatives:
```python
import folium

# Create a new map
m = folium.Map(location=[40, -100], zoom_start=4)

# Add markers for each initiative
for index, row in data.iterrows():
    folium.Marker([row['latitude'], row['longitude']], popup=row['name']).add_to(m)

# Save the map as an HTML file
m.save('participatory_ai_initiatives_map.html')
```
This code creates a new map and adds markers for each initiative. The markers are added using the latitude and longitude coordinates of each initiative. The map is then saved as an HTML file, which can be opened in a web browser to view the interactive map.

## Customizing the Map

You can customize the map by adding additional layers or markers. For example, you can add a layer to show the locations of different types of initiatives. You can use the following code to add a layer:
```python
# Create a new layer
layer = folium.FeatureGroup(name='Initiative Types')

# Add markers for each initiative type
for initiative_type in data['type'].unique():
    initiatives = data[data['type'] == initiative_type]
    for index, row in initiatives.iterrows():
        folium.Marker([row['latitude'], row['longitude']], popup=row['name']).add_to(layer)

# Add the layer to the map
layer.add_to(m)
```
This code creates a new layer and adds markers for each initiative type. The layer is then added to the map.
