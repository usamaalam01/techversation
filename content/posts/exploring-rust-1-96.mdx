## Installing Rust 1.96
To get started with Rust 1.96, you need to install it on your system. You can download the latest version of Rust from the [official Rust installation page](https://www.rust-lang.org/tools/install). Once you have downloaded the installer, follow the instructions to install Rust on your system.

### Verifying the Installation
After installing Rust, you can verify the installation by opening a terminal and typing the following command:
```bash
rustc --version
```
This will display the version of Rust installed on your system.

Rust 1.96 introduces several new features and improvements to the language. Some of the notable features include:

* **New APIs**: Rust 1.96 introduces new APIs for working with strings, arrays, and other data structures.

### Working with Strings
Rust 1.96 introduces new APIs for working with strings. For example, you can use the `String::from` method to create a new string from a string literal:
```rust
let hello = String::from("Hello, World!");
println!("{}", hello);
```
This will output "Hello, World!" to the console.

### Working with Arrays
Rust 1.96 also introduces new APIs for working with arrays. For example, you can use the `array::from` method to create a new array from a list of values:
```rust
let numbers = [1, 2, 3, 4, 5];
let array = array::from(&numbers);
println!("{:?}", array);
```
This will output `[1, 2, 3, 4, 5]` to the console.
