## Introduction

Electrofacies classification is a crucial step in understanding the geological properties of a reservoir. It involves identifying different rock types based on their electrical properties, which can be measured using wireline logs. In this tutorial, we will demonstrate an unsupervised machine learning workflow for electrofacies classification and porosity characterization using wireline logs from the offshore Keta Basin.

The workflow consists of the following steps:

1. Data preprocessing: cleaning and normalizing the wireline log data.
2. Feature selection: selecting the most relevant features from the preprocessed data.
3. K-means clustering: applying K-means clustering to the selected features to classify electrofacies.
4. Porosity estimation: estimating porosity using the classified electrofacies.

## Data Preprocessing

The first step in the workflow is to preprocess the wireline log data. This involves cleaning and normalizing the data to prepare it for feature selection and clustering. The data used in this study consists of six standard wireline logs from Well C, comprising approximately 11,195 samples.

```python
import pandas as pd
import numpy as np

# Load the wireline log data
data = pd.read_csv('wireline_logs.csv')

# Clean and normalize the data
data = data.dropna()  # remove missing values
data = (data - data.mean()) / data.std()  # normalize the data
```

## Feature Selection

The next step is to select the most relevant features from the preprocessed data. In this study, we will use all six wireline logs as features.

```python
# Select the features
features = data[['GR', 'RT', 'RHOB', 'NPHI', 'PEF', 'DT']]
```

## K-means Clustering

Now, we will apply K-means clustering to the selected features to classify electrofacies. The number of clusters (K) is determined using the elbow method.

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

# Determine the number of clusters (K) using the elbow method
silhouette_scores = []
for k in range(2, 10):
    kmeans = KMeans(n_clusters=k)
    cluster_labels = kmeans.fit_predict(features)
    silhouette_avg = silhouette_score(features, cluster_labels)
    silhouette_scores.append(silhouette_avg)

# Plot the silhouette scores to determine the optimal K
import matplotlib.pyplot as plt
plt.plot(range(2, 10), silhouette_scores)
plt.xlabel('Number of Clusters')
plt.ylabel('Silhouette Score')
plt.show()

# Apply K-means clustering with the optimal K
optimal_k = np.argmax(silhouette_scores) + 2
kmeans = KMeans(n_clusters=optimal_k)
cluster_labels = kmeans.fit_predict(features)
```

## Porosity Estimation

Finally, we will estimate porosity using the classified electrofacies. In this study, we will use a simple linear regression model to estimate porosity.

```python
from sklearn.linear_model import LinearRegression

# Estimate porosity using the classified electrofacies
porosity_model = LinearRegression()
porosity_model.fit(cluster_labels.reshape(-1, 1), data['POR'])
porosity_estimates = porosity_model.predict(cluster_labels.reshape(-1, 1))
```

The estimated porosity values can be used to characterize the reservoir and make informed decisions about exploration and production.
