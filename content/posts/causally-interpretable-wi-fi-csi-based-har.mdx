## Introduction

Human Activity Recognition (HAR) is a crucial aspect of various applications, including healthcare, security, and smart homes. Wi-Fi Channel State Information (CSI) has emerged as a promising modality for HAR due to its ability to capture subtle changes in the environment. However, existing deep neural models for CSI-based HAR rely on continuous latent representations, which lack causal interpretability and symbolic controllability.

In this tutorial, we will explore the implementation of a causally interpretable Wi-Fi CSI-based HAR system using discrete latent compression and LTL (Linear Temporal Logic) rule extraction. We will discuss the key concepts, architecture, and implementation details of the model, and provide working code examples to demonstrate the approach.

## Background

Wi-Fi CSI is a measure of the wireless channel's frequency response, which can be used to capture the effects of human activities on the environment. Deep neural models have achieved strong predictive performance on CSI-based HAR, but they rely on continuous latent representations that are difficult to interpret and control.

Discrete latent compression and LTL rule extraction offer a promising solution to this problem. By compressing the high-dimensional CSI data into a discrete latent space, we can extract meaningful patterns and relationships that are causally interpretable. LTL rule extraction enables us to represent these patterns in a symbolic and controllable form, which can be used for decision-making and reasoning.

## Architecture

The architecture of our causally interpretable Wi-Fi CSI-based HAR system consists of three main components:

1. **CSI Data Preprocessing**: This component is responsible for collecting and preprocessing the CSI data. We will use a Wi-Fi CSI dataset that contains samples of CSI measurements collected from a wireless network.
2. **Discrete Latent Compression**: This component compresses the high-dimensional CSI data into a discrete latent space using a variational autoencoder (VAE).
3. **LTL Rule Extraction**: This component extracts LTL rules from the discrete latent space using a rule extraction algorithm.

### CSI Data Preprocessing

We will use a sample Wi-Fi CSI dataset that contains 1000 samples of CSI measurements collected from a wireless network. Each sample is represented as a vector of 30 dimensions, where each dimension corresponds to a subcarrier of the Wi-Fi channel.

```python
import numpy as np

# Load the CSI dataset
csi_data = np.load('csi_dataset.npy')

# Preprocess the CSI data
csi_data = csi_data[:, :, 0]  # Select the first antenna
csi_data = csi_data[:, :, np.newaxis]  # Add a new axis for the channel dimension
```

### Discrete Latent Compression

We will use a VAE to compress the high-dimensional CSI data into a discrete latent space. The VAE consists of an encoder and a decoder, where the encoder maps the input data to a continuous latent space, and the decoder maps the continuous latent space to the input data.

```python
import torch
import torch.nn as nn
import torch.optim as optim

# Define the VAE architecture
class VAE(nn.Module):
    def __init__(self, input_dim, latent_dim):
        super(VAE, self).__init__()
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, 128),
            nn.ReLU(),
            nn.Linear(128, latent_dim * 2)
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, 128),
            nn.ReLU(),
            nn.Linear(128, input_dim)
        )

    def encode(self, x):
        z_mean, z_log_var = self.encoder(x).chunk(2, dim=1)
        return z_mean, z_log_var

    def reparameterize(self, z_mean, z_log_var):
        std = torch.exp(0.5 * z_log_var)
        eps = torch.randn_like(std)
        z = z_mean + eps * std
        return z

    def decode(self, z):
        return self.decoder(z)

# Initialize the VAE and optimizer
vae = VAE(input_dim=csi_data.shape[1], latent_dim=10)
optimizer = optim.Adam(vae.parameters(), lr=0.001)

# Train the VAE
for epoch in range(100):
    optimizer.zero_grad()
    z_mean, z_log_var = vae.encode(csi_data)
    z = vae.reparameterize(z_mean, z_log_var)
    reconstructed_data = vae.decode(z)
    loss = ((reconstructed_data - csi_data) ** 2).mean()
    loss.backward()
    optimizer.step()
    print(f'Epoch {epoch+1}, Loss: {loss.item()}')
```

### LTL Rule Extraction

We will use a rule extraction algorithm to extract LTL rules from the discrete latent space. The algorithm works by identifying patterns and relationships in the latent space and representing them in a symbolic and controllable form.

```python
import numpy as np

# Extract LTL rules from the discrete latent space
def extract_ltl_rules(z):
    rules = []
    for i in range(z.shape[0]):
        rule = []
        for j in range(z.shape[1]):
            if z[i, j] > 0.5:
                rule.append(f'x{j} > 0.5')
            else:
                rule.append(f'x{j} <= 0.5')
        rules.append(' && '.join(rule))
    return rules

# Extract LTL rules from the discrete latent space
z = vae.reparameterize(*vae.encode(csi_data))
rules = extract_ltl_rules(z)
print(rules)
```
