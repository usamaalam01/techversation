## Introduction
The ability of Large Reasoning Models (LRMs) to discover and synthesize long-tail facts from dispersed sources is a crucial aspect of their application in real-world scenarios. However, this capability remains under-evaluated. To address this, the PolitNuggets benchmark was introduced, providing a comprehensive framework for evaluating the performance of LRMs in agentic discovery of long-tail political facts. In this tutorial, we will provide a step-by-step guide on how to use PolitNuggets to benchmark agentic discovery of long-tail political facts.

## Setting up the Benchmark
To get started with PolitNuggets, you need to set up the benchmark on your local machine. This involves installing the required dependencies and downloading the dataset. You can install the dependencies using pip:
```bash
pip install -r requirements.txt
```
Once the dependencies are installed, you can download the dataset using the following command:
```bash
python download_dataset.py
```
This will download the PolitNuggets dataset, which consists of a collection of long-tail political facts and their corresponding sources.

## Running Experiments
To run experiments with PolitNuggets, you need to define a configuration file that specifies the model, dataset, and evaluation metrics. An example configuration file is provided in the `configs` directory:
```python
# config.py
model = "lrms"
dataset = "politnuggets"
evaluation_metrics = ["accuracy", "f1_score"]
```
You can then run the experiment using the following command:
```bash
python run_experiment.py --config config.py
```
This will run the experiment with the specified model, dataset, and evaluation metrics.

## Analyzing Results
Once the experiment is complete, you can analyze the results using the `analyze_results.py` script:
```python
python analyze_results.py --config config.py
```
This will generate a report that includes the performance metrics for the model, such as accuracy and F1 score.

## Customizing the Benchmark
PolitNuggets provides a flexible framework for customizing the benchmark to suit your specific needs. You can modify the configuration file to change the model, dataset, or evaluation metrics. Additionally, you can add custom evaluation metrics or modify the existing ones to better suit your use case.
