## Introduction
The history of American space exploration is a long and fascinating one, with numerous objects having been launched into space over the years. From satellites and spacecraft to flags and other symbolic items, these launches have played a significant role in shaping the country's space program. In this post, we'll take a closer look at the oldest American objects in space and explore how to use publicly available APIs to retrieve information about these launches.

## Historical Background
The first American object to be launched into space was a V-2 rocket, which was launched on February 24, 1949. However, the oldest American object still in space is a topic of debate among space enthusiasts. According to an article published on [Ars Technica](https://arstechnica.com/space/2026/07/whats-the-oldest-americana-flown-in-space/), some of the oldest American objects in space include a Revolutionary War flag and the Statue of Liberty.

## Using APIs to Retrieve Launch Information
To retrieve information about historical launches, we can use publicly available APIs such as the [NASA API](https://api.nasa.gov/). This API provides access to a wide range of data, including launch information, spacecraft details, and more.

```python
import requests

# Set API endpoint and parameters
endpoint = "https://api.nasa.gov/planetary/launches"
params = {
    "api_key": "YOUR_API_KEY",
    "start_date": "1949-01-01",
    "end_date": "1960-12-31"
}

# Send GET request to API
response = requests.get(endpoint, params=params)

# Parse JSON response
data = response.json()

# Print launch information
for launch in data["launches"]:
    print(launch["name"], launch["date"])
```

## Exploring Launch Data
Once we have retrieved the launch data, we can explore it further to gain insights into the history of American space exploration. For example, we can use the data to create a timeline of launches, or to analyze the types of spacecraft that were launched during different periods.

```python
import pandas as pd

df = pd.DataFrame(data["launches"])
```
