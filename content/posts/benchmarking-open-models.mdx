## Introduction

The concept of agentic capabilities in artificial intelligence (AI) refers to a model's ability to take actions and make decisions autonomously. As AI models become increasingly complex and powerful, it's essential to evaluate their agentic capabilities to ensure they align with our expectations and values. Recently, HuggingFace published a blog post titled "Is it agentic enough? Benchmarking open models on your own tooling," which highlights the importance of benchmarking open models using custom tooling. In this post, we'll summarize the key points from HuggingFace's article, explain why it matters to developers, and provide our take on the broader implications.

## What Happened

HuggingFace's blog post emphasizes the need for developers to evaluate open models using their own tooling, rather than relying solely on pre-defined benchmarks. This approach allows developers to assess a model's agentic capabilities in a more realistic and relevant context. By using custom tooling, developers can create benchmarks that are tailored to their specific use case, which can help identify potential issues or limitations in the model. The post also provides examples of how to create custom benchmarks using popular libraries and frameworks.

## Why it Matters to Developers

Benchmarking open models using custom tooling is crucial for developers because it enables them to evaluate a model's performance and capabilities in a more accurate and relevant way. Pre-defined benchmarks may not always reflect the specific requirements and constraints of a developer's project, which can lead to incorrect assumptions about a model's abilities. By creating custom benchmarks, developers can ensure that the model they choose is well-suited for their specific use case and can perform as expected.

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# Load pre-trained model and tokenizer
model = AutoModelForSequenceClassification.from_pretrained("distilbert-base-uncased")
tokenizer = AutoTokenizer.from_pretrained("distilbert-base-uncased")

# Create custom benchmark using a specific dataset and evaluation metric
def custom_benchmark(model, dataset, metric):
    # Tokenize the dataset and create a data loader
    tokenized_dataset = tokenizer(dataset, return_tensors="pt", padding=True, truncation=True)
    data_loader = torch.utils.data.DataLoader(tokenized_dataset, batch_size=32, shuffle=True)

    # Evaluate the model on the custom dataset and metric
    model.eval()
    total_correct = 0
    with torch.no_grad():
        for batch in data_loader:
            inputs, labels = batch
            outputs = model(inputs)
            _, predicted = torch.max(outputs.logits, dim=1)
            total_correct += (predicted == labels).sum().item()

    accuracy = total_correct / len(dataset)
    return accuracy

# Evaluate the model using the custom benchmark
accuracy = custom_benchmark(model, dataset, "accuracy")
print(f"Model accuracy on custom dataset: {accuracy:.4f}")
```
