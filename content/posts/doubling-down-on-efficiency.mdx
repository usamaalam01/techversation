## Introduction to the Breakthrough

In a recent [post](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores) on the OpenAI blog, the team shared an exciting breakthrough in their pursuit of creating more efficient AI models. By enabling two specific API settings, they were able to triple their scores on the ARC-AGI-3 benchmark. This achievement is a significant milestone in the development of Artificial General Intelligence (AGI) and has important implications for developers working in the field.

## Understanding the ARC-AGI-3 Benchmark

The ARC-AGI-3 benchmark is a challenging test designed to evaluate the ability of AI models to reason and learn. It consists of a series of tasks that require the model to understand and apply complex concepts, making it an ideal benchmark for assessing the performance of AGI models. The fact that OpenAI was able to achieve such a significant boost in performance on this benchmark is a testament to the power of their approach.

## The Two API Settings

So, what are the two API settings that made all the difference? According to the OpenAI blog post, the settings focus on retaining reasoning and enabling compaction. Retaining reasoning allows the model to maintain a deeper understanding of the concepts it has learned, while enabling compaction enables the model to compress its knowledge into a more efficient form. This combination of settings allows the model to learn more efficiently and effectively, resulting in significantly improved performance.

### Code-Level Implications

To understand the impact of these settings on the code level, let's consider a simple example. Suppose we're using a language model like GPT-5.6 to generate text based on a given prompt. By enabling the settings that retain reasoning and enable compaction, we can improve the model's ability to understand the context and generate more coherent text.
```python
import torch
from transformers import GPT5ForConditionalGeneration, GPT5Tokenizer

# Initialize the model and tokenizer
model = GPT5ForConditionalGeneration.from_pretrained('gpt5-6')
tokenizer = GPT5Tokenizer.from_pretrained('gpt5-6')

# Define the prompt
prompt = "Write a story about a character who learns to play the guitar."

# Enable the settings that retain reasoning and enable compaction
model.config.retain_reasoning = True
model.config.enable_compaction = True

# Generate the text
input_ids = tokenizer.encode(prompt, return_tensors='pt')
output = model.generate(input_ids, max_length=200)

# Print the generated text
print(tokenizer.decode(output[0], skip_special_tokens=True))
```
In this example, enabling the settings that retain reasoning and enable compaction allows the model to generate more coherent and contextually relevant text.
