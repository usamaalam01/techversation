## Introduction
The Swift Observatory was launched in 2004 as a gamma-ray burst observatory, designed to detect and study gamma-ray bursts in the universe. However, recent solar storms have pushed its orbit lower, and it is now in danger of burning up in Earth's atmosphere as soon as this year. To prevent this from happening, NASA has launched an emergency mission to intercept the observatory and raise its orbit.

## The Mission
The mission involves using a spacecraft called Link, developed by Katalyst Space Technologies, to intercept the Swift Observatory and attach a propulsion system to it. The propulsion system will then be used to raise the observatory's orbit and prevent it from burning up in the atmosphere. The Link spacecraft launched on Friday and is expected to reach the Swift Observatory in the coming weeks.

## Tracking the Swift Observatory's Orbit
To track the Swift Observatory's orbit, we can use the `skyfield` library in Python. The `skyfield` library provides a simple and efficient way to calculate the positions of celestial bodies in the solar system.

```python
import numpy as np
from skyfield.api import load, Topos

# Load the timescale and ephemeris
ts = load.timescale()
e = load('de421.bsp')

# Define the Swift Observatory's orbit
swift_orbit = e['earth barycenter'] + e['swift']

# Define the time range for the orbit
t = ts.now() + np.arange(0, 30, 0.1)

# Calculate the Swift Observatory's position at each time step
position = swift_orbit.at(t)

# Print the position
print(position)
```

This code loads the timescale and ephemeris using the `skyfield` library, defines the Swift Observatory's orbit, and calculates its position at each time step over a range of 30 days.
