## Introduction

Autonomous improvement loops are crucial for developing trustworthy AI systems. However, the improvement process is often external and opaque, making it difficult to trust the outcomes. Regimes, a new tool introduced in the paper [Regimes: An Auditable, Held-Out-Gated Improvement Loop Demonstrated on LongMemEval with ActiveGraph](https://arxiv.org/abs/2606.10241), addresses this issue by providing an event-sourced agent runtime. In this tutorial, we will explore how to use Regimes to create autonomous improvement loops with ActiveGraph on LongMemEval.

## Setting up the Environment

To get started with Regimes, you need to set up the environment. First, install the required libraries using pip:
```python
pip install regimes activegraph longmemeval
```
Next, import the necessary modules:
```python
import regimes
from activegraph import ActiveGraph
from longmemeval import LongMemEval
```
## Creating an Event-Sourced Agent Runtime

Regimes uses an event-sourced agent runtime to provide a transparent improvement process. To create an event-sourced agent runtime, you need to define the agent's behavior using a set of events. For example:
```python
class Agent(regimes.Agent):
    def __init__(self):
        self.events = []

    def add_event(self, event):
        self.events.append(event)

    def get_events(self):
        return self.events
```
## Integrating with ActiveGraph

ActiveGraph is a graph-based framework for autonomous systems. To integrate Regimes with ActiveGraph, you need to create an ActiveGraph instance and pass it to the Regimes agent:
```python
graph = ActiveGraph()
agent = Agent()
agent.add_event("init")
graph.add_node(agent)
```
## Evaluating with LongMemEval

LongMemEval is a benchmark for evaluating the performance of autonomous systems. To evaluate the Regimes agent with LongMemEval, you need to create a LongMemEval instance and pass it to the Regimes agent:
```python
evaluator = LongMemEval()
agent.add_event("evaluate")
evaluator.evaluate(agent)
```
## Putting it all Together

Now that we have set up the environment, created an event-sourced agent runtime, integrated with ActiveGraph, and evaluated with LongMemEval, let's put it all together. Here's an example code snippet that demonstrates the autonomous improvement loop:
```python
import regimes
from activegraph import ActiveGraph
from longmemeval import LongMemEval

class Agent(regimes.Agent):
    def __init__(self):
        self.events = []

    def add_event(self, event):
        self.events.append(event)

    def get_events(self):
        return self.events

graph = ActiveGraph()
agent = Agent()
agent.add_event("init")
graph.add_node(agent)

evaluator = LongMemEval()
agent.add_event("evaluate")
evaluator.evaluate(agent)

print(agent.get_events())
```
This code snippet creates an event-sourced agent runtime, integrates it with ActiveGraph, and evaluates it with LongMemEval. The output will be a list of events that the agent has executed, providing a transparent and auditable improvement process.
