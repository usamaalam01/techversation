## Introduction

Machine learning systems are increasingly being used in high-stakes socioeconomic settings, such as loan approval, hiring, and law enforcement. However, these systems can often display bias, which can have serious consequences. To address this issue, researchers have proposed a novel approach: treating fairness as a symmetry operation. In this tutorial, we'll delve into the details of this approach and provide a step-by-step guide on how to implement it in practice.

## What is Symmetry in Machine Learning?

Symmetry in machine learning refers to the idea that a model's outputs should remain unchanged under certain transformations of the input data. For example, if we have a model that predicts income based on demographic features, we would expect the model's outputs to remain the same if we swap the gender or race of the individual, holding all other features constant. This is because income should not depend on these sensitive attributes.

## Formalizing Bias as a Symmetry Breaking Operation

The approach proposed in the paper [Detecting and Mitigating Bias by Treating Fairness as a Symmetry Operation](https://arxiv.org/abs/2606.06514) formalizes bias as a symmetry breaking operation. Specifically, a classifier is considered fair if its outputs remain invariant under the counterfactual operation of switching a sensitive attribute, with merit features held fixed.

To illustrate this concept, let's consider an example. Suppose we have a model that predicts loan approval based on features such as income, credit score, and gender. If the model's outputs change when we swap the gender of the individual, holding all other features constant, then the model is biased.

## Implementing Loss-Based Regularization

To achieve fairness, the authors propose using loss-based regularization. The idea is to add a regularization term to the loss function that penalizes the model for violating the symmetry constraint.

Here's an example of how we can implement this in Python:
```python
import numpy as np
import torch
import torch.nn as nn

# Define a simple neural network model
class Model(nn.Module):
    def __init__(self):
        super(Model, self).__init__()
        self.fc1 = nn.Linear(5, 10)  # input layer (5) -> hidden layer (10)
        self.fc2 = nn.Linear(10, 1)  # hidden layer (10) -> output layer (1)

    def forward(self, x):
        x = torch.relu(self.fc1(x))  # activation function for hidden layer
        x = self.fc2(x)
        return x

# Define the loss function with regularization term
def loss_fn(model, x, y, sensitive_attribute):
    outputs = model(x)
    loss = nn.MSELoss()(outputs, y)

    # Calculate the regularization term
    sensitive_attribute = sensitive_attribute.long()
    outputs_sensitive = model(x)
    outputs_counterfactual = model(x)
    outputs_counterfactual[sensitive_attribute == 1] = model(x[sensitive_attribute == 1])
    regularization_term = nn.MSELoss()(outputs_sensitive, outputs_counterfactual)

    # Add the regularization term to the loss function
    loss += 0.1 * regularization_term
    return loss

# Train the model
model = Model()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(100):
    optimizer.zero_grad()
    loss = loss_fn(model, x, y, sensitive_attribute)
    loss.backward()
    optimizer.step()
    print(f'Epoch {epoch+1}, Loss: {loss.item()}')
```
In this example, we define a simple neural network model and a loss function that includes a regularization term. The regularization term is calculated by swapping the sensitive attribute and comparing the model's outputs.
