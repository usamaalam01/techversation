## Introduction

Recursive reasoning systems are designed to alternate between acquiring new evidence and refining an accumulated understanding. Two crucial design choices are typically left implicit: how to represent the evolving reasoning state and when to stop iterating. In this tutorial, we will address both of these issues by representing the reasoning state as an epistemic state graph and implementing a termination condition.

## State Representation

The state representation is a critical component of any recursive reasoning system. It encodes the extracted claims and evidence accumulated during the reasoning process. We can represent the state as a graph, where each node represents a claim or piece of evidence, and the edges represent the relationships between them.

```python
import networkx as nx

class EpistemicStateGraph:
    def __init__(self):
        self.graph = nx.DiGraph()

    def add_claim(self, claim):
        self.graph.add_node(claim)

    def add_evidence(self, evidence, claim):
        self.graph.add_node(evidence)
        self.graph.add_edge(evidence, claim)

    def get_state(self):
        return self.graph
```

## Termination Condition

The termination condition determines when the recursive reasoning system should stop iterating. A common approach is to use a fixed number of iterations or a threshold for the accumulated evidence. We can implement a termination condition based on the number of iterations.

```python
class TerminationCondition:
    def __init__(self, max_iterations):
        self.max_iterations = max_iterations
        self.current_iteration = 0

    def check_termination(self):
        self.current_iteration += 1
        return self.current_iteration >= self.max_iterations
```
