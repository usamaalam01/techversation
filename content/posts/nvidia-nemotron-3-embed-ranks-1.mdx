## Introduction to NVIDIA Nemotron 3 Embed
NVIDIA Nemotron 3 Embed has recently topped the RTEB leaderboard, showcasing its exceptional performance in agentic retrieval tasks. In this tutorial, we will delve into the world of Nemotron 3 Embed and explore its capabilities. We will provide a step-by-step guide on how to use this model, along with practical code examples to help you get started.

## Setting Up the Environment
To begin working with NVIDIA Nemotron 3 Embed, you need to have the following dependencies installed:
- `transformers` library by Hugging Face
- `torch` library for PyTorch
- `numpy` library for numerical computations

You can install these dependencies using pip:
```bash
pip install transformers torch numpy
```
## Loading the Nemotron 3 Embed Model
To load the Nemotron 3 Embed model, you can use the `transformers` library. Here's an example code snippet:
```python
from transformers import AutoModel, AutoTokenizer

# Load the Nemotron 3 Embed model and tokenizer
model_name = "nvidia/nemotron3-embed"
model = AutoModel.from_pretrained(model_name)
tokenizer = AutoTokenizer.from_pretrained(model_name)
```
## Preprocessing Input Data
Before feeding input data to the model, you need to preprocess it using the `tokenizer`. Here's an example code snippet:
```python
# Define a sample input text
input_text = "This is a sample input text."

# Preprocess the input text using the tokenizer
inputs = tokenizer(input_text, return_tensors="pt")
```
## Generating Embeddings
To generate embeddings using the Nemotron 3 Embed model, you can use the `model` object. Here's an example code snippet:
```python
# Generate embeddings for the input text
outputs = model(**inputs)
embeddings = outputs.last_hidden_state[:, 0, :]
```
## Using Nemotron 3 Embed for Agentic Retrieval
Nemotron 3 Embed can be used for various agentic retrieval tasks, such as text similarity search and question answering. Here's an example code snippet demonstrating how to use the model for text similarity search:
```python
# Define a sample query text
query_text = "This is a sample query text."

# Preprocess the query text using the tokenizer
query_inputs = tokenizer(query_text, return_tensors="pt")

# Generate embeddings for the query text
query_outputs = model(**query_inputs)
query_embeddings = query_outputs.last_hidden_state[:, 0, :]

# Calculate the similarity between the query embeddings and the input embeddings
similarity = torch.cosine_similarity(query_embeddings, embeddings)
```
