## Introduction

Machine learning (ML) engineering agents often waste compute resources by rediscovering known techniques for each new competition. This is because every competition is a cold start, and agents must learn from scratch. To address this issue, researchers have proposed HASTE, a hierarchical multi-agent system that accumulates skills across competitions. In this tutorial, we will explore how to implement HASTE in practice.

HASTE organizes cross-competition knowledge into three scope tiers: global, domain, and competition-specific. Each tier is coupled to a matching agent level, and an orchestrator coordinates domain-specific agents. This hierarchical approach enables agents to accumulate skills and reduce waste.

## HASTE Architecture

The HASTE architecture consists of three main components:

1. **Global Agent**: The global agent is responsible for accumulating skills across all competitions. It learns general techniques that can be applied to various domains.
2. **Domain Agent**: The domain agent is responsible for accumulating skills within a specific domain. It learns techniques that are relevant to that domain and can be applied to multiple competitions.
3. **Competition Agent**: The competition agent is responsible for accumulating skills for a specific competition. It learns techniques that are relevant to that competition and can be applied to a specific task.

### Orchestrator

The orchestrator is responsible for coordinating the domain-specific agents. It assigns tasks to agents based on their expertise and ensures that agents are working together efficiently.

## Implementing HASTE

To implement HASTE, we will use Python and the PyTorch library. We will define a simple example to demonstrate how HASTE can be used to accumulate skills across competitions.

```python
import torch
import torch.nn as nn

# Define the global agent
class GlobalAgent(nn.Module):
    def __init__(self):
        super(GlobalAgent, self).__init__()
        self.fc1 = nn.Linear(5, 10)  # input layer (5) -> hidden layer (10)
        self.fc2 = nn.Linear(10, 5)  # hidden layer (10) -> output layer (5)

    def forward(self, x):
        x = torch.relu(self.fc1(x))  # activation function for hidden layer
        x = self.fc2(x)
        return x

    def __init__(self):
```

## Training the Agents

To train the agents, we will use a simple example where we have three competitions: competition A, competition B, and competition C. Each competition has a specific task, and we want to accumulate skills across competitions.

```python
# Define the tasks for each competition
competition_a_task = torch.randn(5, 5)
competition_b_task = torch.randn(5, 5)
competition_c_task = torch.randn(5, 5)

# Train the global agent
global_agent = GlobalAgent()
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(global_agent.parameters(), lr=0.01)
for epoch in range(100):
    optimizer.zero_grad()
    output = global_agent(competition_a_task)
    loss = criterion(output, competition_a_task)
    loss.backward()
    optimizer.step()

# Train the domain agent
domain_agent = DomainAgent()
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(domain_agent.parameters(), lr=0.01)
for epoch in range(100):
    optimizer.zero_grad()
    output = domain_agent(competition_b_task)
    loss = criterion(output, competition_b_task)
    loss.backward()
    optimizer.step()

# Train the competition agent
competition_agent = CompetitionAgent()
criterion = nn.MSELoss()
optimizer = torch.optim.SGD(competition_agent.parameters(), lr=0.01)
for epoch in range(100):
    optimizer.zero_grad()
    output = competition_agent(competition_c_task)
    loss = criterion(output, competition_c_task)
    loss.backward()
    optimizer.step()
```

## Accumulating Skills

To accumulate skills across competitions, we will use the hierarchical approach proposed by HASTE. We will first train the global agent on all competitions, then train the domain agent on a specific domain, and finally train the competition agent on a specific competition.

```python
# Accumulate skills across competitions
global_agent_output = global_agent(competition_a_task)
domain_agent_output = domain_agent(competition_b_task)
competition_agent_output = competition_agent(competition_c_task)

# Use the accumulated skills to improve performance
improved_output = global_agent_output + domain_agent_output + competition_agent_output
```
