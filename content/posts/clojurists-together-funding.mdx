## Introduction to Clojurists Together
Clojurists Together is a non-profit organization that provides funding for open source Clojure projects. The organization aims to support the growth and development of the Clojure ecosystem by providing financial resources to developers working on open source projects. In their recent [announcement](https://www.clojuriststogether.org/news/q2-2026-funding-announcement/), they have opened applications for Q2 2026 funding.

## Applying for Funding
To apply for funding, developers need to submit a proposal outlining their project, its goals, and how it will benefit the Clojure community. The proposal should include a detailed description of the project, its current status, and a plan for how the funding will be used. Developers can submit their proposals through the Clojurists Together [website](https://www.clojuriststogether.org/).

### Eligibility Criteria
To be eligible for funding, projects must meet certain criteria. These include:
* The project must be open source and licensed under a permissive license.
* The project must be related to Clojure or the Clojure ecosystem.
* The project must have a clear plan for how the funding will be used.
* The project must have a clear plan for how it will benefit the Clojure community.

## Supported Projects
Clojurists Together supports a wide range of projects, including tools, libraries, and frameworks. Some examples of projects that have received funding in the past include:
* [ClojureScript](https://clojurescript.org/), a compiler for Clojure that targets JavaScript.
* [Leiningen](https://leiningen.org/), a build tool for Clojure projects.
* [CIDER](https://cider.mx/), an Emacs mode for Clojure development.

## Getting Started with Clojure
If you're new to Clojure, getting started can seem daunting. However, there are many resources available to help you learn. The official [Clojure website](https://clojure.org/) has a comprehensive guide to getting started, including tutorials, documentation, and a list of resources.

### Installing Clojure
To get started with Clojure, you'll need to install it on your system. You can do this by installing [Leiningen](https://leiningen.org/), which is the de facto build tool for Clojure. Once you have Leiningen installed, you can create a new Clojure project using the following command:
```clojure
lein new myproject
```
This will create a new directory called `myproject` containing a basic Clojure project.

### Writing Clojure Code
Clojure is a functional programming language that is designed to be concise and expressive. Here's an example of a simple Clojure function:
```clojure
(defn greet [name]
  (str "Hello, " name))
```
This function takes a `name` parameter and returns a string greeting.
