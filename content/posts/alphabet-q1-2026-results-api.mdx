## Introduction
Alphabet, the parent company of Google, has announced its Q1 2026 results, and with it, a new API for developers to access financial data. The API, dubbed "Alphabet Finance API," provides a range of tools and endpoints for retrieving company information, financial statements, and other relevant data. In this tutorial, we will explore the capabilities of the API and provide a step-by-step guide on how to use it.

## Getting Started
To get started with the Alphabet Finance API, you will need to register for an API key on the [Alphabet Investor Relations website](https://abc.xyz/investor/news/news-details/2026/Alphabet-Announces-First-Quarter-2026-Results-2026-X-ge4Dm6bf/default.aspx). Once you have registered, you will receive an API key that you can use to authenticate your requests.

### Authentication
The Alphabet Finance API uses a simple authentication mechanism based on API keys. To authenticate your requests, you will need to include your API key in the `Authorization` header of your HTTP requests. Here is an example of how to do this using Python:
```python
import requests

api_key = "YOUR_API_KEY_HERE"
headers = {
    "Authorization": f"Bearer {api_key}"
}

response = requests.get("https://api.alphabet.com/finance/v1/company", headers=headers)
```
## Endpoints
The Alphabet Finance API provides a range of endpoints for retrieving company information and financial statements. Some of the most useful endpoints include:

* `GET /finance/v1/company`: Retrieves company information, including name, ticker symbol, and industry.
* `GET /finance/v1/financials`: Retrieves financial statements, including income statements and balance sheets.
* `GET /finance/v1/press-releases`: Retrieves press releases and other news articles related to the company.

Here is an example of how to use the `GET /finance/v1/company` endpoint to retrieve company information:
```python
import requests

api_key = "YOUR_API_KEY_HERE"
headers = {
    "Authorization": f"Bearer {api_key}"
}

response = requests.get("https://api.alphabet.com/finance/v1/company", headers=headers)

if response.status_code == 200:
    company_info = response.json()
    print(company_info)
else:
    print("Error:", response.status_code)
```
This code retrieves the company information and prints it to the console.
