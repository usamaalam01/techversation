## Introduction
Quantum Frog is a two-player cooperative game that introduces a novel quantized-time mechanic, where the environment advances only when a player acts. The game is built on top of the classic arcade game Frogger and requires two frogs to cross an 8x8 grid of traffic and reach the far side together. In this tutorial, we will explore how to build a basic version of Quantum Frog using Python and reinforcement learning.

## Game Environment
The game environment consists of an 8x8 grid, where each cell can be either empty or occupied by a frog or traffic. The frogs can move up, down, left, or right, and the traffic moves horizontally across the grid. The game ends when both frogs reach the far side of the grid or when one of the frogs is hit by traffic.

### Game State
The game state can be represented as a 2D array, where each cell contains information about the current state of the cell. We can use the following representation:
- 0: Empty cell
- 1: Frog 1
- 2: Frog 2
- 3: Traffic

```python

game_state = np.zeros((8, 8))

# Place the frogs at the starting position
game_state[0, 0] = 1
game_state[0, 1] = 2

# Place the traffic at the starting position
```

## Reinforcement Learning
We will use reinforcement learning to train the frogs to work together and cross the grid. The reinforcement learning algorithm will learn to take actions based on the current state of the game and the rewards it receives.

### Actions
The frogs can take the following actions:
- 0: Move up
- 1: Move down
- 2: Move left
- 3: Move right

```python
# Define the possible actions
actions = [0, 1, 2, 3]
```

### Rewards
The frogs receive rewards based on their actions and the current state of the game. We can use the following rewards:
- +1: Frog moves closer to the far side of the grid
- -1: Frog moves away from the far side of the grid
- -10: Frog is hit by traffic
