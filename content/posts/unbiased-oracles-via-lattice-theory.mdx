## Introduction
Non-agentic AI that estimates probabilities of future events faces a self-reference problem. Once its answer is learned and acted upon, it can change the very probability it was asked to report. To address this issue, the Scientist AI programme advocates for asking only counterfactual questions, evaluated as if the answer had no influence. In this tutorial, we'll delve into the concept of unbiased canonical set-valued oracles via lattice theory and provide a practical implementation using Python.

## Background: Lattice Theory
Lattice theory is a branch of mathematics that studies partially ordered sets, known as lattices. A lattice is a set with a partial order relation, where every pair of elements has a least upper bound (join) and a greatest lower bound (meet). Lattices can be used to represent complex relationships between elements and can be applied to various fields, including computer science and AI.

## Unbiased Canonical Set-Valued Oracles
An unbiased canonical set-valued oracle is a non-agentic AI that estimates probabilities of future events without being influenced by its own predictions. This is achieved by asking counterfactual questions, which are evaluated as if the answer had no influence on the outcome. To implement such an oracle, we need to define a lattice structure that represents the relationships between events and their probabilities.

### Lattice Structure

class Lattice:
    def __init__(self, events):
        self.events = events
        self.relations = self.build_relations()

    def build_relations(self):
        relations = {}
        for event in self.events:
            relations[event] = []
            for other_event in self.events:
                if event != other_event:
                    # Calculate the relationship between events
                    relation = self.calculate_relation(event, other_event)
                    relations[event].append((other_event, relation))
        return relations
