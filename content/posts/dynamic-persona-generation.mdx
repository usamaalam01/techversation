## Introduction

Large Language Models (LLMs) are increasingly being applied in interpersonal domains such as counseling and peer support, where establishing human-AI rapport is crucial yet remains challenging. To address this challenge, we introduce a novel approach for conditioning LLMs with in-group personas. This approach first identifies a user's primary concern and brief personal context, then generates a personalized persona to enhance human-AI rapport.

## Background

The concept of persona generation is not new, but its application in human-AI interaction is still in its infancy. Traditional persona generation methods rely on static personas that are predefined and do not adapt to the user's context. In contrast, our approach uses dynamic persona generation, which takes into account the user's primary concern and brief personal context to generate a personalized persona.

## LLM Conditioning

The generated persona is used to condition the LLM, which then responds to the user's input. The LLM conditioning process involves fine-tuning the LLM on the generated persona.

```python
class LLMConditioningModule:
    def __init__(self, model_name):
        self.model = AutoModelForSequenceClassification.from_pretrained(model_name)

    def condition_llm(self, persona):
        # Fine-tune LLM on generated persona
        self.model.train()
        optimizer = torch.optim.Adam(self.model.parameters(), lr=1e-5)

        for epoch in range(5):
            optimizer.zero_grad()
            outputs = self.model(**persona)
            loss = outputs.loss
            loss.backward()
            optimizer.step()

        self.model.eval()
```
