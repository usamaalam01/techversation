## Introduction
Large Language Models (LLMs) have become increasingly popular in natural language processing tasks, but their performance can be limited by the use of regex filters. In this tutorial, we will explore the concept of isolating LLM alignment from regex filters and discuss the potential benefits and limitations of this approach.

The idea of isolating LLM alignment from regex filters is rooted in the fact that regex filters can sometimes hinder the performance of LLMs. By removing the regex filter and using a specially designed corpus, we can gain insight into the true capabilities of the LLM.

## Understanding LLM Alignment
LLM alignment refers to the process of fine-tuning a pre-trained LLM to perform a specific task. This is typically done by adding a task-specific layer on top of the pre-trained model and training the entire network end-to-end.

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# Load pre-trained LLM and tokenizer
model = AutoModelForSequenceClassification.from_pretrained("bert-base-uncased")
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

# Define a custom dataset class for our corpus
class LLMAlignmentDataset(torch.utils.data.Dataset):
    def __init__(self, corpus, labels):
        self.corpus = corpus
        self.labels = labels

    def __getitem__(self, idx):
        text = self.corpus[idx]
        label = self.labels[idx]

        # Preprocess the text using the tokenizer
        inputs = tokenizer(text, return_tensors="pt")

        # Return the preprocessed inputs and label
        return inputs, label

    def __len__(self):
        return len(self.corpus)
```

## Designing a Corpus to Bypass Regex Filters
To truly test the capabilities of an LLM, we need a corpus that is designed to bypass regex filters. This can be achieved by creating a corpus that contains a diverse range of texts, including those that are likely to be filtered out by regex.

```python
import pandas as pd

# Load the corpus from a CSV file
corpus = pd.read_csv("corpus.csv")

# Define the labels for the corpus
labels = corpus["label"]

# Create an instance of the custom dataset class
dataset = LLMAlignmentDataset(corpus["text"], labels)
```

## Training the LLM without Regex Filters
Now that we have our corpus and dataset, we can train the LLM without using regex filters.

```python
# Create a data loader for the dataset
batch_size = 32
data_loader = torch.utils.data.DataLoader(dataset, batch_size=batch_size, shuffle=True)

# Define the device (GPU or CPU) to use for training
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# Move the model to the device
model.to(device)

# Define the optimizer and loss function
optimizer = torch.optim.Adam(model.parameters(), lr=1e-5)
loss_fn = torch.nn.CrossEntropyLoss()

# Train the model
for epoch in range(5):
    model.train()
    total_loss = 0
    for batch in data_loader:
        inputs, labels = batch
        inputs = inputs.to(device)
        labels = labels.to(device)

        # Zero the gradients
        optimizer.zero_grad()

        # Forward pass
        outputs = model(**inputs)
        loss = loss_fn(outputs.logits, labels)

        # Backward pass
        loss.backward()

        # Update the model parameters
        optimizer.step()

        # Accumulate the loss
        total_loss += loss.item()

    print(f"Epoch {epoch+1}, Loss: {total_loss / len(data_loader)}")
```

## Evaluating the Performance of the LLM
After training the LLM, we can evaluate its performance using a test dataset.

```python
# Create a test dataset and data loader
test_dataset = LLMAlignmentDataset(test_corpus["text"], test_labels)
test_data_loader = torch.utils.data.DataLoader(test_dataset, batch_size=batch_size, shuffle=False)

# Evaluate the model on the test dataset
model.eval()
total_correct = 0
with torch.no_grad():
    for batch in test_data_loader:
        inputs, labels = batch
        inputs = inputs.to(device)
        labels = labels.to(device)

        # Forward pass
        outputs = model(**inputs)
        logits = outputs.logits

        # Get the predicted labels
        _, predicted = torch.max(logits, dim=1)

        # Accumulate the correct predictions
        total_correct += (predicted == labels).sum().item()

# Calculate the accuracy
accuracy = total_correct / len(test_labels)
print(f"Test Accuracy: {accuracy:.4f}")
```
