## Introduction

The field of natural language processing (NLP) has seen significant advancements in recent years, with the development of large language models and high-quality embeddings. ## What are Multilingual Embeddings?

Multilingual embeddings are a type of language representation that allows models to understand and generate text in multiple languages. These embeddings are trained on large datasets of text from various languages, enabling them to capture the nuances of each language and facilitate cross-lingual understanding. The quality of multilingual embeddings is crucial in determining the performance of NLP models, particularly in tasks such as language translation, text classification, and information retrieval.

## Granite Embedding Multilingual R2

The Granite Embedding Multilingual R2 is a significant release in the NLP community, offering high-quality multilingual embeddings with a 32K context. This means that the model can capture long-range dependencies in text, allowing for better understanding and representation of complex language structures. The embeddings are trained on a large dataset of text from multiple languages, resulting in a model that can effectively handle languages with diverse grammatical structures and vocabulary.

The release of Granite Embedding Multilingual R2 under the Apache 2.0 license makes it accessible to developers and researchers, enabling them to integrate the embeddings into their NLP models and applications. This open-source release is expected to accelerate the development of multilingual NLP models, particularly in areas such as language translation, sentiment analysis, and text summarization.

### Code Example

To demonstrate the usage of Granite Embedding Multilingual R2, consider the following Python code example:
```python
import torch
from transformers import AutoModel, AutoTokenizer

# Load the Granite Embedding Multilingual R2 model and tokenizer
model = AutoModel.from_pretrained("ibm/granite-embedding-multilingual-r2")
tokenizer = AutoTokenizer.from_pretrained("ibm/granite-embedding-multilingual-r2")

# Define a sample text in multiple languages
text = ["Hello, how are you?", "Bonjour, comment vas-tu?", "Hola, ¿cómo estás?"]

# Preprocess the text using the tokenizer
inputs = tokenizer(text, return_tensors="pt")

# Generate embeddings using the model
embeddings = model(**inputs)

# Print the embeddings
print(embeddings.last_hidden_state[:, 0, :])
```
