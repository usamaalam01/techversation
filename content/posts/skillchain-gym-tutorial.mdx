## Introduction
Production planning is a critical aspect of manufacturing, and it has become increasingly important to consider workforce capability as a decision variable. Certifications lapse when skills are not maintained, new products require skills the current workforce does not hold, and reskilling competes for the same worker hours needed for production. Existing operations benchmarks usually treat labor as exogenous, while SkillChain-Gym is a benchmark that addresses this issue.

## Setting Up SkillChain-Gym
To get started with SkillChain-Gym, you need to install the required libraries. You can do this by running the following command:
```bash
pip install gym
```
Once you have installed the required libraries, you can import SkillChain-Gym in your Python script:
```python
import gym
from skillchain_gym import SkillChainGym
```
## Key Concepts
SkillChain-Gym is designed to simulate a production environment where workforce capability is a decision variable. The key concepts in SkillChain-Gym are:

* **Workforce**: The workforce is represented as a set of workers with different skills and certifications.
* **Products**: The products are represented as a set of tasks that require specific skills and certifications.
* **Reskilling**: Reskilling is the process of training workers to acquire new skills and certifications.
* **Disruptions**: Disruptions are events that affect the production environment, such as changes in demand or supplier availability.

## Implementing SkillChain-Gym
To implement SkillChain-Gym, you need to define the production environment, including the workforce, products, and disruptions. You can do this by creating a `SkillChainGym` object and passing in the required parameters:
```python
env = SkillChainGym(
    num_workers=10,
    num_products=5,
    num_skills=3,
    disruption_probability=0.1
)
```
Once you have defined the production environment, you can simulate the production process using the `step` method:
```python
state, reward, done, info = env.step(action)
```
The `step` method takes an action as input, which is a vector of reskilling decisions for each worker. The method returns the next state, reward, done flag, and info dictionary.

## Working Code Example
Here is a working code example that demonstrates how to use SkillChain-Gym to optimize production planning:
```python
import gym
from skillchain_gym import SkillChainGym
import numpy as np

# Define the production environment
env = SkillChainGym(
    num_workers=10,
    num_products=5,
    num_skills=3,
    disruption_probability=0.1
)

# Define the reskilling policy
def reskilling_policy(state):
    # Reskill workers to acquire new skills and certifications
    action = np.zeros((env.num_workers, env.num_skills))
    for i in range(env.num_workers):
        for j in range(env.num_skills):
            if state[i, j] < 0.5:
                action[i, j] = 1
    return action

# Simulate the production process
state = env.reset()
done = False
while not done:
    action = reskilling_policy(state)
    state, reward, done, info = env.step(action)
    print("Reward:", reward)
```
