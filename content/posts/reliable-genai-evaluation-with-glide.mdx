## Introduction to GLIDE and Prediction-Powered Inference

The evaluation of agentic systems is a critical task that requires unbiased estimates with valid uncertainty. However, standard practice often navigates between costly human annotation and biased LLM-as-judge proxies. To address this challenge, the GLIDE library has been introduced, providing a reliable method for debiased estimates with valid confidence intervals. In this tutorial, we will explore the GLIDE library and demonstrate how to use it for prediction-powered inference.

### What is Prediction-Powered Inference?

Prediction-powered inference (PPI) is a technique that combines human annotation and LLM-as-judge proxies to produce debiased estimates with valid confidence intervals. PPI methods have been scattered across various papers, making it challenging to implement and compare them. The GLIDE library aims to provide a unified framework for PPI, making it easier to evaluate agentic systems.

## Installing and Importing GLIDE

To get started with GLIDE, you need to install the library using pip:
```bash
pip install glide
```
Once installed, you can import the library in your Python code:
```python
import glide
```
### Loading and Preprocessing Data

Before using GLIDE, you need to load and preprocess your data. The library provides a simple interface for loading datasets and preprocessing them:
```python
from glide.datasets import load_dataset
from glide.preprocessing import preprocess_data

# Load the dataset
dataset = load_dataset("your_dataset")

# Preprocess the data
preprocessed_data = preprocess_data(dataset)
```
## Using GLIDE for Prediction-Powered Inference

GLIDE provides a simple interface for performing prediction-powered inference. You can use the `glide.inference` function to generate debiased estimates with valid confidence intervals:
```python
from glide.inference import prediction_powered_inference

# Perform prediction-powered inference
estimates, confidence_intervals = prediction_powered_inference(preprocessed_data)
```
### Interpreting Results

The `estimates` and `confidence_intervals` returned by the `prediction_powered_inference` function provide valuable insights into the performance of your agentic system. You can use these results to evaluate the reliability of your system and identify areas for improvement:
```python
print("Estimates:", estimates)
print("Confidence Intervals:", confidence_intervals)
```

## Advanced Topics and Customization

GLIDE provides several advanced features and customization options, allowing you to tailor the library to your specific needs. For example, you can use the `glide.config` module to configure the library's behavior:
```python
from glide.config import Config

# Create a custom configuration
config = Config()

# Set custom parameters
config.max_iter = 1000
config.learning_rate = 0.01

# Use the custom configuration
estimates, confidence_intervals = prediction_powered_inference(preprocessed_data, config)
```
