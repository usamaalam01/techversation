## Introduction
The Clinical Harness is a novel approach to organizing medical AI around accountable capabilities that persist across time. In this tutorial, we will delve into the world of Clinical Harness and explore how to build a runtime governance architecture for registering, orchestrating, guarding, and monitoring AI-enabled clinical capabilities. We will use osteoporosis as an exemplar and provide working code examples to demonstrate the concepts.

## Clinical Harness Overview
The Clinical Harness is designed to address the limitations of traditional medical AI models, which are often isolated and lack accountability. The Clinical Harness provides a framework for registering, orchestrating, guarding, and monitoring AI-enabled clinical capabilities, ensuring that they are transparent, explainable, and fair. The architecture consists of several components, including:

* **Skill Registry**: a database of registered clinical skills, each with its own set of attributes and capabilities.
* **Orchestrator**: a module responsible for coordinating the execution of clinical skills and ensuring that they are used in a way that is consistent with clinical guidelines and protocols.
* **Guard**: a module responsible for monitoring the execution of clinical skills and detecting any anomalies or errors.
* **Monitor**: a module responsible for tracking the performance of clinical skills and providing feedback to clinicians and developers.

## Guarding and Monitoring Clinical Skills
The Guard and Monitor are responsible for detecting anomalies and tracking the performance of clinical skills. We will use a simple statistical approach to detect outliers and anomalies.

```python
import numpy as np

class Guard:
    def __init__(self, registry):
        self.registry = registry

    def guard(self, patient_data):
        # Detect anomalies in the patient data
        for skill_name, result in patient_data["results"].items():
            skill = self.registry.get_skill(skill_name)
            # Calculate the mean and standard deviation of the result
            mean = np.mean(result)
            std = np.std(result)
            # Check if the result is an outlier
            if np.abs(result - mean) > 2 * std:
                # Raise an alert if the result is an outlier
                raise Exception(f"Anomaly detected in {skill_name} result")

class Monitor:
    def __init__(self, registry):
        self.registry = registry

    def monitor(self, patient_data):
        # Track the performance of clinical skills
        for skill_name, result in patient_data["results"].items():
            skill = self.registry.get_skill(skill_name)
            # Calculate the accuracy of the skill
            accuracy = np.mean(result)
            # Store the accuracy in the skill's record
            skill["accuracy"] = accuracy

# Create a Guard and Monitor

monitor = Monitor(registry)

# Guard and monitor the execution of clinical skills for a patient
```
