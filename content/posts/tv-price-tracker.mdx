## Introduction

The recent price cut of the Hisense RGB LED TV on its release day has sparked interest in monitoring TV prices. As a developer, you can build a TV price tracker to stay updated on the latest prices. In this tutorial, we will show you how to use Python and web scraping to track TV prices.

## Getting Started

To start, you need to install the required libraries. We will use `beautifulsoup4` for web scraping and `requests` for making HTTP requests. You can install these libraries using pip:
```bash
pip install beautifulsoup4 requests
```
## Inspecting the Website

Before we start scraping, we need to inspect the website that contains the TV prices. For this example, we will use the website of an online retailer like Best Buy or Amazon. Let's say we want to scrape the price of the Hisense UR9 65-inch TV from Best Buy.

Open the website in your browser and navigate to the product page. Right-click on the page and select "Inspect" or "View Source" to open the developer tools. In the Elements tab, find the HTML element that contains the price.

## Scraping the Price

Now that we have found the HTML element that contains the price, we can write a Python script to scrape it. We will use the `requests` library to make an HTTP request to the website and the `BeautifulSoup` library to parse the HTML response.
```python
import requests
from bs4 import BeautifulSoup

# URL of the product page
url = "https://www.bestbuy.com/site/hisense-65-ur9-4k-rgb-led-tv/6488216.p"

# Make an HTTP request to the website
response = requests.get(url)

# Parse the HTML response using BeautifulSoup
soup = BeautifulSoup(response.text, 'html.parser')

# Find the HTML element that contains the price
price_element = soup.find('div', {'class': 'price-block'})

# Extract the price from the HTML element
price = price_element.find('span', {'class': 'price'}).text.strip()

print(price)
```
This script will print the current price of the Hisense UR9 65-inch TV.

## Handling Price Changes

To handle price changes, we need to store the current price and compare it with the previous price. We can use a dictionary to store the prices, where the key is the product name and the value is the current price.
```python
prices = {}

def get_price(url):
    # Make an HTTP request to the website
    response = requests.get(url)

    # Parse the HTML response using BeautifulSoup
    soup = BeautifulSoup(response.text, 'html.parser')

    # Find the HTML element that contains the price
    price_element = soup.find('div', {'class': 'price-block'})

    # Extract the price from the HTML element
    price = price_element.find('span', {'class': 'price'}).text.strip()

    return price

def update_price(product_name, url):
    current_price = get_price(url)
    if product_name in prices:
        previous_price = prices[product_name]
        if current_price != previous_price:
            print(f"Price change detected: {product_name} was {previous_price}, now {current_price}")
    prices[product_name] = current_price

# Update the price of the Hisense UR9 65-inch TV
update_price("Hisense UR9 65-inch TV", "https://www.bestbuy.com/site/hisense-65-ur9-4k-rgb-led-tv/6488216.p")
```
This script will update the price of the Hisense UR9 65-inch TV and print a message if the price has changed.

## Scheduling the Script

To run the script periodically, we can use a scheduler like `schedule`. We can schedule the script to run every hour, for example.
```python
import schedule
import time

def job():
    update_price("Hisense UR9 65-inch TV", "https://www.bestbuy.com/site/hisense-65-ur9-4k-rgb-led-tv/6488216.p")

schedule.every(1).hours.do(job)  # run every hour

while True:
    schedule.run_pending()
    time.sleep(1)
```
This script will run the `update_price` function every hour and update the price of the Hisense UR9 65-inch TV.
