## Building a Basic AI Safety Framework
To understand the concept of AI safety, let's build a basic framework using Python. We'll create a simple AI model that can detect harmful content in text.

```python
import nltk
from nltk.sentiment import SentimentIntensityAnalyzer

# Download the required NLTK data
nltk.download('vader_lexicon')

# Initialize the sentiment intensity analyzer
sia = SentimentIntensityAnalyzer()

# Define a function to detect harmful content
def detect_harmful_content(text):
    # Analyze the sentiment of the text
    sentiment = sia.polarity_scores(text)
    
    # Check if the sentiment is negative
    if sentiment['compound'] < -0.5:
        return True
    else:
        return False

# Test the function
text = "This is a harmful message."
print(detect_harmful_content(text))  # Output: True
```
