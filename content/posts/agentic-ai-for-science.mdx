## Introduction
The field of artificial intelligence has made tremendous progress in recent years, with the development of large language models (LLMs) being a significant milestone. These models have the potential to revolutionize the way we approach scientific research, enabling autonomous, agentic AI systems to assist in data collection, analysis, and decision-making. In this tutorial, we'll delve into the world of agentic AI for science, exploring two novel frameworks that leverage a hybrid Local Body, Remote Brain architecture.

## Background
The paper "Experiments in Agentic AI for Science" (arXiv:2605.26305v1) introduces two frameworks for developing autonomous, agentic AI in scientific workflows. The first agent, DeepTS/DeepCollector, automates large-scale data collection and analysis, while the second agent focuses on more complex tasks. Both systems utilize a hybrid Local Body, Remote Brain architecture, where Python-based local orchestrators invoke LLM cloud backends via Google Colab.

## Implementing the DeepTS/DeepCollector Agent
The DeepTS/DeepCollector agent is designed to automate large-scale data collection and analysis. To implement this agent, you'll need to create a Python script that can interact with your LLM cloud backend. Here's an example code snippet to get you started:
```python
import pandas as pd
from transformers import AutoModelForSequenceClassification, AutoTokenizer

# Define a function to collect data
def collect_data(query):
    # Use the LLM to generate a list of relevant papers
    inputs = tokenizer(query, return_tensors="pt")
    outputs = model(**inputs)
    papers = []
    for paper in outputs:
        papers.append(paper["title"])
    return papers

# Define a function to analyze data
def analyze_data(papers):
    # Use the LLM to analyze the papers and extract relevant information
    analyzed_papers = []
    for paper in papers:
        inputs = tokenizer(paper, return_tensors="pt")
        outputs = model(**inputs)
        analyzed_papers.append(outputs)
    return analyzed_papers

# Test the agent
query = "Experiments in Agentic AI for Science"
papers = collect_data(query)
analyzed_papers = analyze_data(papers)
print(analyzed_papers)
```
