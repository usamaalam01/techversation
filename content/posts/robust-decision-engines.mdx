## Introduction
Decision engines are crucial in various industries, such as finance, logistics, and energy management. These engines use Mixed-Integer Linear Programming (MILP) to output nominally optimal plans. However, small perturbations in costs, demands, or resource availability can invalidate feasibility or trigger discontinuous shifts to qualitatively different solutions. In this tutorial, we will explore the concept of post-solve robustness and provide working code examples in Python to build robust decision engines.

## Post-Solve Robustness
Post-solve robustness refers to the ability of a decision engine to maintain its optimality under small perturbations. This is crucial in real-world applications, where uncertainty and variability are inherent. The paper "Post-Solve Robustness in Decision Engines: Feasible Regions and Smoothness Under Perturbations" [1] provides a comprehensive overview of this concept.

### Feasible Regions
A feasible region is the set of all possible solutions that satisfy the constraints of the problem. In MILP, the feasible region is a polyhedron, which can be represented by a set of linear inequalities. To build a robust decision engine, we need to ensure that the feasible region is large enough to accommodate small perturbations.

```python
import numpy as np
from scipy.optimize import linprog

# Define the coefficients of the objective function
c = np.array([1, 2, 3])

# Define the coefficients of the inequality constraints
A = np.array([[1, 2, 3], [4, 5, 6]])
b = np.array([10, 20])

# Define the bounds of the variables
x_bounds = [(0, None), (0, None), (0, None)]

# Solve the MILP problem
res = linprog(c, A_ub=A, b_ub=b, bounds=x_bounds)

print(res.x)
```

## Smoothness Under Perturbations
Smoothness under perturbations refers to the ability of the decision engine to maintain its optimality under small changes in the input parameters. This can be achieved by using regularization techniques, such as L1 or L2 regularization.

```python
import numpy as np
from scipy.optimize import linprog

# Define the coefficients of the objective function
c = np.array([1, 2, 3])

# Define the coefficients of the inequality constraints
A = np.array([[1, 2, 3], [4, 5, 6]])
b = np.array([10, 20])

# Define the bounds of the variables
x_bounds = [(0, None), (0, None), (0, None)]

# Define the regularization parameter
reg_param = 0.1

# Solve the MILP problem with regularization
res = linprog(c + reg_param * np.ones_like(c), A_ub=A, b_ub=b, bounds=x_bounds)

print(res.x)
```
