### Setting up the API
To get started with the OnePlus API, you'll need to register for a developer account on the OnePlus website. Once you've registered, you'll be given an API key, which you can use to authenticate your requests.

```python
import requests

# Replace with your API key
api_key = "YOUR_API_KEY_HERE"

# Set the API endpoint URL
url = "https://api.oneplus.com/v1/devices"

# Set the headers with your API key
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

# Send a GET request to the API
response = requests.get(url, headers=headers)

# Print the response
print(response.json())
```
