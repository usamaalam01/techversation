## Introduction
The Ignition Index (I) is a validated scalar metric that measures global workspace dynamics in language models. It is based on Global Workspace Theory (GWT), which predicts that information will be either fully processed or not processed at all. In this tutorial, we will explore how to implement the Ignition Index using Python.

The Ignition Index is calculated by fitting a four-parameter sigmoid to per-layer linear probe accuracy as a function of input signal strength. The steepness parameter, beta-hat, is extracted from this sigmoid and used to measure the ignition dynamics of the language model.

## Background
Global Workspace Theory (GWT) is a cognitive architecture that describes how the brain processes information. It suggests that information is processed in a global workspace, where all relevant information is integrated and processed. The Ignition Index is a way to measure this global workspace dynamics in language models.

To calculate the Ignition Index, we need to train a language model and then use a linear probe to measure the accuracy of the model at different layers. The linear probe is a simple neural network that is trained to predict the output of the language model.

## Implementing the Ignition Index
To implement the Ignition Index, we will use the Hugging Face Transformers library in Python. We will train a transformer language model and then use a linear probe to measure the accuracy of the model at different layers.

```python
import torch
from transformers import AutoModelForSequenceClassification, AutoTokenizer
from sklearn.metrics import accuracy_score
from scipy.optimize import curve_fit

# Load pre-trained language model and tokenizer
model = AutoModelForSequenceClassification.from_pretrained("bert-base-uncased")
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

# Define linear probe
class LinearProbe(torch.nn.Module):
    def __init__(self):
        super(LinearProbe, self).__init__()
        self.linear = torch.nn.Linear(768, 8)  # 768 is the hidden size of BERT

    def forward(self, x):
        x = self.linear(x)
        return x

# Initialize linear probe
linear_probe = LinearProbe()

# Define sigmoid function
def sigmoid(x, a, b, c, d):
    return a / (1 + torch.exp(-b * (x - c))) + d

# Define function to calculate Ignition Index
def calculate_ignition_index(model, linear_probe, input_signal_strengths):
    accuracies = []
    for input_signal_strength in input_signal_strengths:
        # Generate input data
        input_data = torch.randn(1, 768) * input_signal_strength

        # Get output from language model
        output = model(input_data)

        # Get output from linear probe
        linear_probe_output = linear_probe(output.last_hidden_state[:, 0, :])

        # Calculate accuracy
        accuracy = accuracy_score(torch.argmax(linear_probe_output, dim=1), torch.tensor([0]))
        accuracies.append(accuracy)

    # Fit sigmoid to accuracies
    popt, _ = curve_fit(sigmoid, input_signal_strengths, accuracies)

    # Calculate Ignition Index
    ignition_index = popt[1]

    return ignition_index

# Calculate Ignition Index
input_signal_strengths = torch.linspace(0, 1, 10)
ignition_index = calculate_ignition_index(model, linear_probe, input_signal_strengths)

print("Ignition Index:", ignition_index)
```
