## Introduction
Long reasoning traces in Large Language Models (LLMs) require reliability estimates before final answers are known. One approach to achieving this is through prefix-conditioned eventual-success estimation, $P(y=1 \mid o_{1:t})$, using prefix-safe observations. In this tutorial, we will delve into the world of Sequential Bayesian Belief Tracking (SBBT) and explore how it can be used to calibrate observation likelihoods and recursively update a two-state belief.

## Bayesian Belief Tracking Basics
Bayesian belief tracking is a probabilistic approach to estimating the state of a system based on observations. In the context of LLMs, the state of the system is typically represented by a binary variable $y$, where $y=1$ indicates a correct answer and $y=0$ indicates an incorrect answer. The observations $o_{1:t}$ are the output of the LLM at each time step.

The goal of Bayesian belief tracking is to estimate the probability of the correct answer given the observations, $P(y=1 \mid o_{1:t})$. This is achieved by recursively updating the belief state using Bayes' rule.

## Prefix-Safe Observations
Prefix-safe observations are a type of observation that is designed to be safe to use in Bayesian belief tracking. The key property of prefix-safe observations is that they do not depend on the future observations. This is important because it allows us to use the observations to update the belief state without worrying about the impact of future observations.

## Sequential Bayesian Belief Tracking (SBBT)
SBBT is a specific implementation of Bayesian belief tracking that uses prefix-safe observations to update the belief state. The SBBT algorithm consists of two main components:

1.  **Observation likelihood calculation**: This involves calculating the likelihood of each observation given the current state of the system.
2.  **Belief update**: This involves updating the belief state using the observation likelihoods and the previous belief state.

The SBBT algorithm can be implemented using the following recursive formula:

$$
P(y=1 \mid o_{1:t}) = \frac{P(o_t \mid y=1) \cdot P(y=1 \mid o_{1:t-1})}{P(o_t \mid o_{1:t-1})}
$$

where $P(o_t \mid y=1)$ is the likelihood of the observation given the correct answer, $P(y=1 \mid o_{1:t-1})$ is the previous belief state, and $P(o_t \mid o_{1:t-1})$ is the likelihood of the observation given the previous observations.

### Implementing SBBT in Python
Here is an example implementation of the SBBT algorithm in Python:
```python
import numpy as np

def calculate_observation_likelihood(observation, correct_answer):
    # Calculate the likelihood of the observation given the correct answer
    if observation == correct_answer:
        return 0.9  # High likelihood if the observation matches the correct answer
    else:
        return 0.1  # Low likelihood if the observation does not match the correct answer

def update_belief_state(previous_belief_state, observation_likelihood, observation):
    # Update the belief state using the observation likelihood and the previous belief state
    numerator = observation_likelihood * previous_belief_state
    denominator = observation_likelihood * previous_belief_state + (1 - observation_likelihood) * (1 - previous_belief_state)
    return numerator / denominator

def sbbt(observations, correct_answer):
    # Initialize the belief state
    belief_state = 0.5  # Initial belief state is 0.5 (neutral)

    # Iterate over the observations
    for observation in observations:
        # Calculate the observation likelihood
        observation_likelihood = calculate_observation_likelihood(observation, correct_answer)

        # Update the belief state
        belief_state = update_belief_state(belief_state, observation_likelihood, observation)

    return belief_state

# Example usage
observations = [1, 1, 0, 1, 1]
correct_answer = 1
belief_state = sbbt(observations, correct_answer)
print("Final belief state:", belief_state)
```
This implementation assumes a simple observation likelihood calculation, where the likelihood of an observation given the correct answer is high if the observation matches the correct answer, and low otherwise. The `update_belief_state` function updates the belief state using the observation likelihood and the previous belief state.
